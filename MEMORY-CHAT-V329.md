# Свежая память в чате — v329, 04.10.2026

## Было → стало

Экран памяти позволял исправлять и отключать отдельные записи, но чат читал только
старую текстовую выжимку из локального State.profile. Теперь перед каждым сообщением
он читает /api/ai/memory и формирует контекст из подтверждённого ответа сервера.

- Берутся только активные записи со scope assistant_prompt, без sensitive.
- Источник explicit/imported/inferred передаётся рядом с текстом. Вывод программы
  помечен гипотезой; явная поправка человека имеет приоритет над старой выжимкой.
- Сохранённая правка действует со следующего сообщения, отключение — со следующего
  чтения. Предыдущий UI-кеш не используется как запасной источник.
- Частичный/повреждённый ответ или отказ чтения не отправляет запрос модели.
  Вопрос остаётся для повтора; общий таймаут и отмена охватывают оба запроса.
- Чтение и правки памяти защищены от поздних ответов после смены аккаунта/эпохи.
  Загрузка контекста для чата не перезаписывает открытый редактор памяти.

## Границы

Свободный старый профиль сохраняется, до 3000 символов, без автоматического разбора.
Фильтр sensitive относится к отдельным записям, а не к произвольному тексту профиля.
Бюджет текстов структурных записей — 1500 символов плюс обозначение источников.

Это подключение существующих записей, не новый автоматический сбор фактов. Создание
записей из разговора и подтверждение новых предположений остаются отдельным этапом.
Тень не должна заявлять, что запомнила новое, без сохранения.

Отключение записи не удаляет её из уже отправленных сообщений и истории разговора.
Проверка перед отправкой не отзывает контекст запроса, который уже ушёл модели.
Качество интерпретации моделью отдельно от правильности собранного контекста.
