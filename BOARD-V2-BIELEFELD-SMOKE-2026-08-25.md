# Board v2 — live Bielefeld source smoke, 2026-08-25

Источник: `https://hsp.sport.uni-bielefeld.de/cgi/webpage.cgi?kursinfo=A34EE5B2DC`

## Что проверено

- Прямой HTTPS fetch официального домена прошёл: HTTP 200, HTML 116076 bytes.
- Страница не содержит JSON-LD и schema.org Microdata, поэтому общий structured-data verifier честно не создаёт candidate.
- В обычной HTML-таблице явно есть курс `Boxen A2/F`, даты до 07.10.2026, ближайшая после времени проверки встреча 26.08.2026, время 19:00–20:30 и площадка `Gymnastikhalle Wertherstraße`.
- Блок места указывает `Lampingstr., 33615 Bielefeld`.
- Блок цены говорит `entgeltfrei` только для перечисленных групп: студенты/учащиеся, сотрудники Uni/HSBI и связанные с Universität Bielefeld лица. Для бронирования упомянуты дополнительные условия.
- Однозначная общедоступная availability/booking CTA на проверенной странице не найдена.

## Решение

Страница остаётся `no-verified-candidate`. Нельзя превращать слово `entgeltfrei` в универсальное «бесплатно» и предлагать курс человеку, чья eligibility неизвестна.

Следующий source-adapter для университетского спорта должен быть привязан к точному официальному домену и версии структуры, извлекать ближайший будущий слот, место и адрес, а также возвращать закрытый audience gate (`student`, `trainee`, `staff`, `affiliate`). Candidate разрешается только если профиль пользователя явно подтверждает подходящую группу и на источнике есть актуальный путь записи/участия. При изменении DOM adapter закрывается, а не переходит к угадыванию по тексту.

Raw HTML не сохраняется в репозитории и не попадает в пользовательский cache.
