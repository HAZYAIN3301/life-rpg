## Шаг 1. Аккаунт разработчика (один раз, ~10 минут)

1. Открой https://chrome.google.com/webstore/devconsole под своим Google-аккаунтом.
2. Прими соглашение и оплати разовый регистрационный взнос ($5) — это делаешь ты.
3. В «Account» укажи контактную почту и подтверди её.

## Шаг 2. Новый элемент (~20 минут)

1. «New item» → загрузи `satoru-attention-chromium-v300.zip`.
2. **Store listing:** название `Satoru Attention`; краткое и полное описание — из
   `STORE-LISTING.md` (EN как основной язык, RU добавить как второй); категория
   «Productivity»; иконка и плитка из `store-kit-v260`; скриншоты из этой папки.
3. **Privacy practices:**
   - Single purpose — текст раздела «Single purpose».
   - Обоснование каждого разрешения (`storage`, `declarativeNetRequest`, `scripting`, `alarms`,
     доступ к сайтам) — раздел «Permission rationale».
   - Remote code: **No**.
   - Data usage: ничего не собирается; отметь три подтверждения (не продаём, не используем
     для несвязанных целей, не для кредитных решений).
   - Privacy policy URL: https://satoruapp.com/browser-companion-privacy.html
4. **Distribution:** «Public» (или «Unlisted», если пока не хочешь показывать в поиске —
   для замка браузера подходят оба варианта).
5. «Submit for review». Проверка обычно занимает от нескольких дней до пары недель; расширение
   с доступом ко всем сайтам и большими списками может проверяться дольше.

## Шаг 3. После одобрения — пришли мне ID

В адресе карточки будет 32-символьный ID (буквы a–p). С ним я:
- заменю на satoruapp.com тестовую ссылку на ZIP кнопкой «Установить из Chrome Web Store»;
- впишу ID в профиль замка браузера и проверю его `plutil -lint`.

Дальше обновления расширения приходят автоматически — без ручного «Обновить».

## Шаг 4. Замок браузера на Mac (делаешь ты, нужен пароль администратора)

Что делает профиль: в Brave и Chrome расширение ставится принудительно — его нельзя
выключить или удалить из `brave://extensions`; приватные окна, окна Tor и гостевой режим
выключены; инструменты разработчика для самого расширения недоступны (чтобы нельзя было
вручную стереть замок из его хранилища). Остальные сайты и DevTools для них работают как обычно.

1. Удали тестовую (распакованную) копию Satoru Attention и установи версию из магазина.
2. Открой полученный от меня `satoru-browser-lock.mobileconfig` двойным щелчком.
3. Системные настройки → Конфиденциальность и безопасность → Профили → «Установить…» →
   пароль администратора.
4. Перезапусти Brave, открой `brave://policy` → «Перезагрузить политики». Все строки должны
   быть со статусом «OK». Если у `ExtensionInstallForcelist` написано, что политика требует
   управляемого устройства, — напиши мне: тогда нужен другой способ (он сложнее).
5. Проверка: в `brave://extensions` у Satoru Attention нет переключателя и кнопки «Удалить»;
   Cmd+Shift+N не открывает приватное окно.

**Как снять профиль в будущем:** Системные настройки → Конфиденциальность и безопасность →
Профили → выбрать «Satoru — browser lock» → «−» → пароль администратора. Это намеренно
неудобно, но возможно всегда.

**Честные границы:** профиль закрывает Brave и Chrome. Safari он не трогает — для Safari включи
Экранное время → Контент и конфиденциальность → Веб-контент → «Ограничить сайты для взрослых»
и отдай код-пароль Экранного времени другу. Системный VPN, другой браузер или другой компьютер
профиль не перекрывает.
