## Блок 1 — Токен-система (фундамент, первым)
**Где:** `public/styles.css` `:root`.
**Сейчас:** `--bg/--panel/--panel2/--line/--text/--muted/--accent/--good/--warn/--bad` + один `--radius` + один `--shadow`. Всё.
**Задача:** добавить, не ломая существующее (новые токены, старые остаются валидными):
- Шкала отступов (`--sp-1..--sp-6`, напр. 4/8/12/16/24/32).
- Шкала радиусов (`--radius-sm/md/lg/pill`) вместо одного значения.
- Шкала глубины/glow (3 уровня: карточка / приподнятая / светящаяся-активная) — под Fortnite-стиль акцентных подсветок.
- Motion-токены (`--ease-out`, `--dur-fast/normal/slow`) — для системной микро-анимации (hover-lift карточек, count-up чисел, easing прогресс-баров).
- **Шрифт**: подобрать/подключить self-hosted display-шрифт под заголовки/крупные цифры (XP/уровень/стрик) — не нарушает zero-dep (это ассет, не JS-зависимость), но резко поднимает ощущение качества почти бесплатно.

Варианты: (a) оставить эмодзи, но систематизировать размер/baseline через CSS; (b) гибрид — inline-SVG для повторяющейся навигации/действий, эмодзи — для флейвора/редкости/характера. ## Блок 5 — IA / перегруз функциями (НЕ визуальная задача — архитектура показа)
1. **Режим Простой/Продвинутый** (идея есть в `BACKLOG.md`, не реализована) — простой режим: домашний экран = только захват + Сегодня + Тень, всё остальное за одним «Ещё».
