# Сохранённые обсуждения — v330

Поручение владельца 04.10: отдельные чаты и контекст, повторная приёмка видео.

## Пользовательский результат

В Тени: список обсуждений, новый чат, название и контекст под «Ещё».
Вопрос сохраняется до обращения к ИИ; ответ — после получения. После перезапуска
открывается последнее обсуждение. История другого чата в запрос не попадает.
Общая память помощника и свежие дела остаются общими — это подписано в настройках чата.
Планирование/разбор недели/Заход начинают отдельное обсуждение с сохранённым назначением.

Старые кнопки выполнения действий после загрузки истории не восстанавливаются:
история не должна повторно создавать задачи или начислять награды. Новое предложение
нужно запросить в разговоре. Вложения не переносятся в соседний чат, их надо выбрать заново.
Локальные черновики переключения сохраняются до перезапуска, не синхронизируются.

## Сохранение и границы

`GET /api/ai/threads`, `GET/PUT /api/ai/threads/<id>`: только текущий аккаунт.
Файлы — `users/<owner>/chat-threads/<id>.json`; запись через writeJsonAtomic.
CAS revision проверяется непосредственно перед синхронной записью. Повтор точного
запроса после потерянной квитанции возвращает прежний результат. Конфликт не затирает
ни серверную историю, ни локальный текст: UI предлагает сохранить отдельную копию.
Отказ сохранения не запускает ИИ; вопрос остаётся для повтора. Повреждённый файл не
заменяется пустым. Граница аккаунта/эпохи/чата отсекает поздние результаты.

Лимиты: 100 обсуждений, 300 сообщений/чат, 512 КиБ/чат, контекст 6000 символов.
Превышение отклоняется, история не обрезается молча. Модели по прежнему передаются
последние 20 успешных сообщений плюс явный контекст, память и актуальные данные.
Автоматическая сводка длинных обсуждений, поиск/архивирование/удаление отдельных
чатов и импорт истории остаются следующими улучшениями. Экспорт аккаунта включает
читаемые чаты в serverOwned.chats; импорт не исполняет и не восстанавливает их.
Удаление аккаунта удаляет и эту папку. Privacy дополнена на пяти языках.

## Повторные ошибки из видео

- «Привычки»: видимый вход «Меньше залипать». В build 11 открывает native Attention;
  браузер честно сообщает, что системная блокировка требует приложения iPhone.
- Вечерний голос больше не читает цели, имя и названия дел и не называет сегодняшнее
  незавершённое дело завтрашним планом.
- Дедлайн календаря занимает отдельное место, а не перекрывает число дня.
- Раскрытый список старых дел сохраняется при перерисовке.
- Шапка чата сокращена; подробности скрыты под «Ещё», история занимает основную область.

## Проверки и остаток

Новые тесты: изоляция, replay, конфликт, отказ записи, порча, недопустимые данные,
отсутствие исполняемых действий в сохранённой истории. Browser QA с синтетическими
аккаунтами: Chromium/WebKit, сохранение/reload, разделение истории/контекста,
503/retry, 409/copy, export/auth, пять языков × две темы × две ширины.
Ответ ИИ в этих тестах подменён, качество реального провайдера ими не доказывается.
Календарь отдельно 320/375/430/1280; native bridge имитируется, device QA остаётся.
Полный suite, commit/deployment/hashcheck — внешняя квитанция CHECKPOINT.
