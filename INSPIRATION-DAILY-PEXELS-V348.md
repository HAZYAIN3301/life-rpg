# Вдохновение: ежедневная поставка Pexels · v348

Обновление29.10: личный TikTok теперь встроен по [v349](./INSPIRATION-INLINE-V349.md).
Поставка Pexels и допуск общего каталога из этого документа не меняются.

Владелец29.10 выбрал бесплатный Pexels API и самостоятельно ввёл ключ в Railway.
Это расширяет лицензированный каталог первого выпуска v323, сохраняя внешний
TikTok и отключённый общий web-discovery. Дизайн B2.17 не перестраивается.

## Доставка

- Сервер использует официальный Pexels API для фото и коротких видео1–180с.
  [Документация](https://www.pexels.com/api/documentation/),
  [лицензия](https://www.pexels.com/license/).
  Поддерживаемые темы перечислены в server-inspiration-pexels-v1.js: природа,
  горы, путешествия, спорт, работа, творчество, учёба и другие конкретные запросы.
  Неизвестная тема не заменяется произвольными красивыми картинками.
- Только заранее заданные query по подтверждённым interest IDs. Личные названия,
  заметки, референсы, история и идентификатор аккаунта не отправляются Pexels.
- Общий серверный topic+format cache: до40 кандидатов на страницу, один fetch на
  UTC-день, single flight и durable receipt. Следующий день двигается по страницам;
  по окончании выдачи повторная первая страница всё равно проходит45-дневный cooldown.
  До3 тем и2 форматов за один запрос, шесть ограниченных параллельных запросов.
  Повторный запрос в тот же день использует кэш; сетевые ошибки имеют backoff.
- После запуска с ключом сервер проверяет два общих public nature-запроса. В журнал
  попадают только публичные sample URLs/IDs, без ключа/профиля. Метаданные API не
  объявляются доказательством воспроизведения. capabilities.inspirationPexelsReady
  означает успешную загрузку обоих форматов из API.
- Медиа идёт напрямую с разрешённых Pexels CDN через img/video. HTML5 controls,
  без autoplay/loop/auto-next, ограниченная длительность; close/ended снимает src
  и останавливает загрузку. Есть load/error/timeout. Файлы видео не копируются на сервер.
- Pexels публикует [видео без звука](https://help.pexels.com/hc/en-us/articles/43126081204505-Why-is-there-no-audio-on-my-video).
  Они явно названы короткими видео, а не музыкальными авторскими эдитами.
  Эдиты авторов требуют отдельного источника; чужие фильмы/музыка не копируются.

## Выбор и хранение

Новый authenticated /api/inspiration/supply читает сохранённый профиль, а не
произвольный клиентский запрос. Возвращает до24 кандидатов, подписанных серверным
HMAC с отдельным namespace и существующим persistent secret. Ключ Pexels есть
только в серверной environment variable PEXELS_API_KEY, не в HTML/JS/ответах API.

Существующий Profile selector выбирает максимум3 карточки, соблюдает интересы,
форматы/feedback/45-дневную историю. Непустой текущий день не дополняется и не
меняется при reload. Явный retry может заполнить лишь ранее пустой непоказанный день.

Выбранные signed candidates сохраняются прежним field-scoped CAS owner вместе с
профилем. HMAC проверяется сервером, клиент не может приписать права произвольному URL.
Другие настройки/tasks/золото/XP не меняются. Lost reply повторяет ту же тройку,
смена account/epoch прекращает позднюю запись. Кэш provider inventory отдельно от
аккаунта; он не является второй базой вкусов или историей показов.

Обычные photo/video карточки сохраняют автора, Pexels и ссылку на исходный материал.
Сохранённый материал после истечения rolling metadata остаётся внешней ссылкой
на свой Pexels source; URL потокового файла не угадывается и не воскрешается.

## Проверки

Тесты: cache single flight/durable failure/retry/corruption; provider query/hosts/
credit/HMAC/429; actual field CAS/lost reply/account switch; viewer end/error/no
autoplay;7 дней cache→selector→shown history с21 разным synthetic provider ID.
Последнее — симуляция дат, не утверждение о семи прожитых днях реальной поставки.
3416 source и184 live на интегрированном кандидате; byte contracts auth/B3/attention.
Реальный API/playback и production version/SHA фиксируются в release receipt.

## Границы

Не все интересы имеют поставщика: аниме, Minecraft и музыкальные эдиты нельзя
заменять stock-видео. Для них сохранённые ссылки доступны, общий каталог требует
допущенных авторов/каналов. Полный offline/VoiceOver и физический iPhone не заявлены.
Pexels API имеет собственные лимиты; приложение не покупает увеличение квот.
