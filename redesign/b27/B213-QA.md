# B2.13 — перенос B2.5 в корневое приложение, 27.10.2026

Переносить структуру, «Сегодня» и «План» уже рационально: их данные и сценарии
подключены. Будущий 3D меняет renderer Логова, а не владельцев данных или навигацию.
Новый дизайн не пересматривается. Это локальный интеграционный кандидат; не релиз.

## Что перенесено

- `/` загружает принятый B2.5: Сегодня / План / Мир / Награды / Племя, настройки
  из шапки, Тень и фокус. Корень и review используют одни `app.js`, UI и startup.
- `app.js` восстановлен от актуального `origin/master` и содержит небольшой
  адаптер установки до init/session lookup. Отклонённый B26 shell не подключён.
  UI/runtime загружаются до core, но State используется лишь после его объявления.
  Модель явно экспортируется из startup для исходных обработчиков.
- Сегодня: реальные задачи/ядро, привычки, фокус и его восстановление, неделя,
  награды, полные исходные заметки/voice/video controls, доска и закрытие дня.
  Заметки сохраняют media/edit/delete/goal/quest owners. Черновики записи и итога
  переживают закрытие панели; это черновики с account scope, не второй data store.
- План: день/неделя/месяц, переносы, намерение/бюджет, цели/шаги/проекты/архив,
  постоянное расписание/исключения, привычки и вдохновение с исходными владельцами.
  «Время и фокус» ведёт к таймеру и настройкам, включая выбор сегодняшнего квеста.
- Результат B3 executor проецируется в новую навигацию; parser не дублируется.
  Notes/Board, даты/масштаб и переходы назад сохраняются в своём URL.
- Существующее Племя доступно внутри shell, без новых механик или 3D обещаний.
- Auth формы/слушатели остаются исходными. `welcome=1` влияет лишь на review:
  показывает вход без logout. В корне параметр не пропускает проверку сессии.
- SW v344 кеширует новый UI/CSS/startup; app.js и worker согласованы.

## Проверено

- TypeScript/esbuild, JS syntax и diff; 174 live/model/baseline проверки.
- Полный исходный suite: 3387 PASS, concurrency=2. Исторические guards не удалены:
  изменены лишь активные app/SW pins; исходный styles.css не изменён.
- Browser 375×812 и desktop1280: корневой запуск, навигация, real source screens.
  Сохранена новая заметка и квест; после перезапуска они присутствуют в аккаунте.
  Фокус start/pause/reload/stop восстановил 00:28 и не создал фактических минут.
  Итог: draft dismiss/reopen, source close/reopen; день возвращён в открытое состояние.
  Серверное подтверждение: `review/b213/final-readback.json`. Старые задачи, заметка,
  цели и покупки сохранены. Новые записи только у изолированного «Тестового героя».
- `?do=capture` открывает и фокусирует настоящий composer, consumed URL не повторяет
  действие. Старые source формы не заменены декоративными кнопками.
- Native: Debug Simulator build/install/launch PASS; 18 Swift core tests PASS
  с чистым scratch path. B3 и attention fixtures байт-в-байт совпадают с web.
  Скрипт запуска native `scripts/run-redesign-simulator.sh` проверен реальным запуском.

## Найдено и исправлено

- Перенос esbuild model внутрь startup спрятал её от window-owners. Отказ записи
  не изменил данные и оставил форму. Регрессионный тест сначала упал, затем прошёл;
  после исправления проверено реальное сохранение/перезапуск.
- Исходные notes icons без scoped CSS становились огромными. Размеры/формы/список
  приведены к B2.5 без изменения доменных обработчиков.
- Закрытие новой панели могло терять несохранённый итог/мысль; добавлены account
  scoped drafts. Подтверждённое сохранение очищает соответствующий capture draft.
- Локальный старый Swift module cache хранил путь из Documents; тесты запущены
  в новом `/private/tmp` scratch, без удаления чужих данных.

## Границы

Системный захват Simulator через CUA вернул ScreenCaptureKit -3811/-3812.
Поэтому native UI, safe-area/keyboard/VoiceOver именно в iOS **не засчитаны**;
мобильные PNG — браузерные, это не снимки физического iPhone. Также не заявлены
полная offline/locale/a11y матрица, реальная запись mic/camera, платные AI-вызовы,
настоящий multiplayer и завершённый переход Логова в 3D.

Production origin/Keychain/auth/B3/attention/native capabilities не изменены.
Нет push/deploy/TestFlight. Рабочую ветку с `d203502b` целиком выпускать нельзя;
чистый кандидат создаётся отдельной веткой от свежего `origin/master` без B26 файлов.

## Воспроизвести

В web-worktree: `node redesign/b27/build-live.mjs`, затем
`npm run review --prefix redesign/b27`. Настоящий корень: http://localhost:8771/.
Review: http://localhost:8771/redesign/live.html; старт: тот же URL с `?welcome=1`.

В native: `zsh scripts/run-redesign-simulator.sh /путь/к/web-worktree` при одном
запущенном iPhone Simulator. Используется только loopback Debug origin и отдельный
локальный WK store; физический телефон к localhost этой машины так не подключается.
