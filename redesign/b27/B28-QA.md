# B2.8 — проверка 26.10.2026

База B2.7: 0f66144b. Макет B2.5 сохранён. Build-time adapter добавляет входы
render/focus/toast к копии движка; исходные app.js/index.html/styles.css и native
код не менялись. Новая поверхность не подключена к service-worker shell.

- TypeScript/esbuild, 98/98 model/regression/baseline tests, 51/51 профильных
  tests focus-session-sync/evening-writes/task-actual/commitment-store/habit-two-minute.
- 13 новых поведенческих проверок: stale edit/account/epoch, failed write/retry,
  concurrent taps, повтор completion, сохранение служебных полей, focus stop,
  потерянная квитанция банка минут и конфликт фактического времени.
- Browser 375/390/1280: сохранены композиция/сцена/строки/навигация, формы,
  keyboard autofocus, реальные сферы, создать и изменить квест; completion/undo,
  заметка, итог дня, отметка привычки. Все эти данные повторно загружены сервером.
- Фокус 2:47 → остановить без completion: `actualMin=2`, `done=false`,
  `xpAwarded=0`, `goldAwarded=0`. После выполнения — `done=true`, 50 XP / 21 gold.
  Повторная загрузка не создаёт ещё один квест. Прямой GET readback:
  `review/b28-server-readback.json` (только изолированные тестовые данные).
- Настоящий чат Тени открывается; тестовый аккаунт без AI показывает подключение.
  Платный AI-запрос не выполнялся.
- iOS 26.5 Simulator / Satoru iPhone 14: установленная native Debug-оболочка
  открыла новый root через localhost:8773. Сегодня и заметки показали данные,
  сохранённые браузером. PNG: `review/b28-ios-today.png`, `b28-ios-notes.png`.

Найденные и исправленные дефекты: старый global theme менял макет;
после замены массива задач банком времени completion использовал старый объект;
прежний toast падал без host; уведомление pending-focus не обновлялось после
receipt; форма legacy-квеста не подсвечивала единственную skillId-сферу.

## Границы и следующий шаг

- Это первая вертикаль переноса, не всё готовое приложение. Доска, План,
  Награды, Мир, Племя, Время/Настройки остаются интерактивным B2.7 preview.
  Переход обозначен явно. Логово остаётся 2D-сценой принятого макета, арт-трек 3D
  не затронут. Внешние изображения сцены по-прежнему требуют сети.
- Новые voice/video capture, note→goal, полноценный чат в стиле B2.5,
  редактирование связи цели, управление наградой с главной ещё требуют переноса.
  note→quest и actual writer подключены; полный UI-сценарий этих двух действий
  ещё не прогнан. Не выдавать наличие вызова за прохождение сценария.
- Сбой записи, lost receipt и account fence проверены моделями/координатором;
  browser offline/network fault injection не проводился. VM tests не заменяют
  реальный backend: happy-path отдельно проверен браузером и HTTP readback.
- Повреждённые данные блокируют штатные writers; новые формы не предлагают
  восстановления повреждённых хранилищ. Конфликт банка минут сохраняет таймер;
  нужен отдельный интерфейс ручного разрешения такой редкой коллизии.
- Полный 3391-test runtime suite в этом шаге не запускался. Нет production,
  физического iPhone, полного VoiceOver/200% text/localization QA.
- IAB сообщил общий MutationObserver warning без источника до и после iframe
  загрузок; прежний известный warning остаётся неатрибутированным. Исправленная
  ошибка toast после 16:05 UTC больше не воспроизводится.

Следующий этап: подключить принятую поверхность Плана (день/неделя/месяц),
переиспользуя этот адаптер и существующие writers. Сначала календарные задачи,
затем цели/шаги и связанные перемещения. Не переносить старые renderers.

Ветка содержит исторический отклонённый d203502b. Не публиковать всю ветку;
перед release переносить только принятые файлы на свежий origin/master,
интегрировать runtime entry и пройти полный релизный gate.
