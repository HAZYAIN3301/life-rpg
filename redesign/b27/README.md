## B2.8 — Сегодня с данными аккаунта, дизайн B2.5

Проверить: http://localhost:8771/redesign/phone.html.
Прямой вход: http://localhost:8771/redesign/live.html.
Остальные разделы макета: http://127.0.0.1:8772/preview.html.

Подключены создание/правка квестов, completion/undo с существующей экономикой,
уточнение фактического времени, привычки, текстовые заметки, итог дня, фокус.
Тень открывает существующий серверный чат; без провайдера предлагает подключение.
Реальные сферы и ID аккаунта не подменяются примерами B2.5. Ошибка не закрывает
форму; таймер сохраняет абсолютное намерение записи до запроса и повторяет его
без прибавления минут дважды. Очередь сессий фокуса остаётся существующей.

`npm run build --prefix redesign/b27` собирает preview и live, затем
`npm test --prefix redesign/b27`: 98 тестов. Дополнительно 51 профильный тест
движка, TypeScript и node --check. QA и границы: [B28-QA.md](B28-QA.md).

Для native review при работающем изолированном web-сервере 8771:
`node redesign/b27/serve-live.mjs`, Debug origin `http://localhost:8773`.
Это прозрачный локальный proxy, `/` открывает live.html; auth и данные обслуживает
тот же сервер. Native source не менялся. Собранная копия движка получает только
проверенные по единственному совпадению hooks; оригинальный app.js неизменён.

Доска, остальные разделы и создание новых аудио/видео пока не перенесены на
аккаунт. Навигация явно предлагает отдельный макет, не смешивает его с записями.
Новый чат Тени ещё требует визуального переноса. Полная локализация, VoiceOver,
offline и физический iPhone не проверены. Никакого production deployment.
