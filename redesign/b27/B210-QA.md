# B2.10 — План и полные настройки

Локальный live entry в принятой оболочке B2.5. Использует настоящие Store/API и
владельцев данных; проверен на встроенном «Тестовом герое» в изолированном
`.qa-b26-data`. Это не production и не новый native-релиз.

## Просмотр

Из корня worktree: `npm run review --prefix redesign/b27`.

- [Цели на телефоне](http://localhost:8771/redesign/phone.html?screen=goals)
- [Настройки на телефоне](http://localhost:8771/redesign/phone.html?screen=settings)
- [План без рамки](http://localhost:8771/redesign/live.html#plan)

Если нужна чистая проверка, на стартовом экране выбрать «Тестовый герой».
Сервисы/ключи и личные данные для этого не требуются.

## Что подключено

- Цели: Сейчас / Все / Карта; проекты, родительские связи, сроки, основные и
  фоновые сферы, состояния/архив, массовые действия, шаги, числовые метрики и лог.
  Шаг становится обычным связанным квестом через GoalStepQuestV1. Сохранение
  goals/tasks/groups идёт через исходный goalDataCommit, без обхода CAS/WAL.
- Постоянное расписание: отдельный слой RoutineV2 в календаре и Сегодня,
  фиксированное/гибкое время, занятия без времени, сферы, улица, чередование
  1–4 недели, исключения и восстановление. Само не создаёт квесты или долг.
  Исходная мастерская недели и её preview/apply доступны из календаря.
- Привычки и Вдохновение: оригинальные формы/обработчики внутри нового shell.
  Вдохновение использует профиль вкуса, допущенную конечную подборку, saved и
  исходный import; не демонстрационный пул prototype.
- Настройки: полный исходный DOM, шесть групп с поиском; дерево сфер/навыков,
  цвета/архив/ритм, фокус, игровой баланс, имя приложения, язык, light/dark/system,
  акцент/звук/движение, Тень/локальная модель/подключения, профиль/пароль/PIN/
  устройства, данные/приватность. Скрытые поля сохранены для captureSettingsForm.
  Пароли/ключи не передаются в React snapshot, URL или review evidence.
- Переходы и browser back ждут завершения сохранения настроек. Отказ записи
  сохраняет открытую форму. Язык/акцент/движение пишут только своё поле;
  тема использует persistThemeChoice. Неизменённый экран не вызывает лишнюю запись.

## Исправлено в ходе проверки

Нативные time/date inputs теряли точное введённое значение — добавлен onInput.
В дереве целей исправлен обход родителей. Настройки больше не выбирают nav-кнопку
вместо секции сфер; скрытые группы действительно скрыты. Убраны sticky-кнопки,
перекрывавшие password form, возвращены читаемые заголовки и dark controls.
Hash-навигация сохраняет путь live.html при base href=/; сборка пинит локальные
bundle по hash, исключая смешение нового UI со старым engine в browser cache.

## Границы

Полный runtime suite, физический iPhone, новая native-сборка, VoiceOver,
полная клавиатурная/200%/offline матрица и все пять языков не проверены.
Часть новой составной подписи/дат остаётся на русском. ICS download, все
разрушительные CRUD-действия и routine→count не пройдены через браузер;
соответствующие модели/исходные обработчики покрыты целевыми тестами, не device QA.
Платные AI/photo/weather, OAuth/реальные интеграции и смена пароля не проверены.
Настройки показывают исходные возможности сервиса; перенос UI не добавляет новый
поставщик мотивационных видео. Дополнительные церемонии FirstValue/объявления целей
не заявляются проверенными. Новый визуальный чат Тени, Доска, Мир/Награды/Племя
и их подключение остаются отдельной работой; последние три пока явно preview.

Default `app.js/index.html/styles.css`, accepted generated-компоненты B2.5,
native/auth/B3/attention и отдельный3D-трек не изменены. Не было подагентов,
push/deploy и новых расходов. **Ветку целиком не выпускать: в истории d203502b.**
Перед релизом переносить только принятые файлы на свежую master, подключать entry/
service worker и проходить полный release gate.
