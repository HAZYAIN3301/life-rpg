## Данные и действия

- Настоящий UI покупки: создать предложение1gold → отменить → подтвердить →
  использовать → удалить предложение → reload. Кошелёк22→21, одна новая покупка,
  использование без второго списания, удаление предложения сохраняет чек.
- Все5 прежних чеков побитово равны baseline. Квесты, цели, навыки, эпизоды,
  привычки, их журнал, исходные2 предложения и lootbox неизменны.
- Theme/name/accent возвращены к Satoru/light/#6c8cff. У Кацую сохранено явное
  enabled:true, совпадающее с первоначальным вычисляемым состоянием.
- Вдохновение: существующий пустой день Design явно заполнен Spring через кнопку;
  тот же официальный embed воспроизводит реальные кадры. XP/золото за просмотр нет.
- Форму квеста с поиском вложенной сферы и разными ролями закрыли без создания.
  Цели/координаты/гардероб не изменялись при визуальных проверках.
