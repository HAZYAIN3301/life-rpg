# B2.5 → действующее приложение: структура, Сегодня и План

> Исполнение в текущем изолированном web-worktree, без подагентов.
> Основание: прямое поручение владельца переносить принятый B2.5 в приложение,
> приоритет Сегодня/План; существующая архитектура SwiftUI + WKWebView.

**Goal:** запускать принятый интерфейс через обычный корень приложения с настоящими
данными и исходными native/auth/B3/attention владельцами.
**Architecture:** одна веб-реализация внутри существующего WKWebView. Канонический
public/app.js сохраняет доменную логику; B2.5 подключается отдельным startup adapter
до init. Root и review собираются из одного шаблона, со строгим порядком загрузки.
**Tech:** SwiftUI/WKWebView, существующий JavaScript runtime, React/esbuild.

## Ограничения

- Generated B2.5 не менять. Не переносить отклонённый ShellB26/CSS или его тестовые pins.
- Не создавать второй Store/кошелёк/auth/parser B3. Не менять production origin/Keychain.
- QA только localhost DATA_DIR и Simulator. Физический телефон/TestFlight/production
  не изменять. Публикация остаётся действием владельца.
- История d203502b не входит в чистый интеграционный commit: собрать разрешённый
  срез на свежей origin/master отдельной веткой без изменения текущей рабочей копии.
