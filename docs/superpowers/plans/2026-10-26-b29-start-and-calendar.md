# B2.9 — стартовый экран и подключение календаря

**Goal:** новый вход в мире B2.5; затем действующий календарь в принятом UI.
**Architecture:** сохраняем существующие auth forms/handlers, меняем их композицию
через отдельный DOM presenter. CalendarWorkspace переносим в live coordinator
с ожидаемыми async receipts и реальными сферами; данные — через действующие writers.
**Tech Stack:** существующие React/TypeScript/esbuild + app.js/Store/WAL.
**Spec:** прямое поручение владельца 26.10 «стартовый экран тоже переделай и потом
делай подключение»; принятое направление B2.5 и QA B2.8 — обязательная база.

## Решения и границы

- Стартовый экран трактуем как вход до аккаунта. Мир/герой/Тень, палитра и
  начертания B2.5; короткий смысл «Твои дела. Твой мир». Возвратный вход — сразу
  email/пароль; регистрация и восстановление остаются доступны. Не придумывать
  пользователей, рейтинг или обещания результатов. Сохранить legacy PIN.
- Auth обработчики, имена форм/полей, ID ошибок, автозаполнение и recovery-код
  сохраняются. Никакого второго login API или хранения паролей в browser storage.
- Подключение: календарь день/неделя/месяц, единые квесты с Сегодня, редактирование,
  completion/undo, перенос/undo, намерение недели и доступное время дня, ICS.
- Основная структура Плана сохраняется. Цели/Привычки/Вдохновение пока отдельные
  preview-разделы; не подмешивать их примерные данные в live аккаунт.
- Move использует commitmentDataCommit и штатное снятие активной границы,
  StuckTask.notePostpone; сохраняет actual/награды/служебные поля. Пакетная запись
  целиком, со stale/owner guard; повтор не добавляет перенос второй раз.
- weeks[week].dayBudgetsV1 и intentionSkillIdsV1 — дополнительные поля, без
  изменения existing intention/review. Никаких новых dataset/API endpoints.
- Native source, auth/B3/attention, 3D/питомцы и публикация за пределами шага.
  Подагенты не используются по AGENTS.md владельца.

## Review focus

Пароль/код в storage или telemetry; утрата PIN/reset; boolean Promise ложный успех;
перенос защищённого квеста без снятия границы; 1–4 минуты не превращаются в 5;
ядро >3; переезд между неделями/месяцами; неизвестная сфера; потеря server receipt;
выход с сохранённой формой и последующее изменение аккаунта; пустой календарь.

## Приёмка

Старт сразу узнаётся как Satoru и ведёт в существующий аккаунт. Календарь читает
те же задания, что Сегодня, и подтверждает запись сервером. Визуальная структура
B2.5 сохраняется. Прохождение targeted tests не выдаётся за full release/iPhone QA.
