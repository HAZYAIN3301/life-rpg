# Daily Inspiration Implementation Plan

**Goal:** Каждый день поставлять новые реальные материалы по подтверждённым интересам,
сохраняя B2.17 и существующий профиль, дневную фиксацию и историю показов.

**Architecture:** Серверный поставщик лицензированных фото/коротких видео и общий
кэш тематических страниц; клиент выбирает до3 карточек прежним Profile selector.
В профиль сохраняются только выбранные реальные кандидаты через текущий CAS owner.
Ключ поставщика остаётся на сервере. Pexels выбран владельцем29.10; ключ введён
владельцем в Railway. Stock-видео не называются авторскими эдитами. Последним нужен
отдельный источник авторов; TikTok остаётся внешним по существующему контракту.

**Tech Stack:** Node.js/CommonJS, существующие browser modules, node:test, React B2.17.

## Constraints

- Без платных запросов/регистраций/изменения privacy без решения владельца.
- Никакого скрейпинга TikTok, копирования чужого видео или ложных playback receipts.
- Источник/автор/лицензия, ошибки и нехватка показываются честно.
- Нет autoplay/auto-next/бесконечной ленты/XP за просмотр.
- Сегодняшняя непустая подборка неизменна; 45-дневная история блокирует повторы.
- Бизнес-данные и профиль сохраняются прежними владельцами, не прямым JSON/PUT.

- [x] Authenticated supply endpoint: запрос только по сохранённому профилю;

- [x] Подключение до фиксации дня, выбор и сохранение<=3 новых кандидатов с CAS;
