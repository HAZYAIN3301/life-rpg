## Как продолжить

Прочитать актуальные AGENTS/AGENTS-PROTOCOL и START-HERE этого репозитория, затем нужную
главу выше. Выбрать одну реальную ситуацию, один подтверждённый путь, миссию, кадр
доказательства и один следующий шаг. Перед публикацией отдельно проверить язык,
доступность функции, ссылку входа и конкретный авторский материал. Даты, цены,
платежи, релизы в магазинах и результаты пользователей не выводятся из учебных примеров.

Перенос не меняет auth/B3/attention, нативный handoff, экономику, пользовательские данные
и очередь продукта. Новые съёмки, публикации контента и обещания роста не выполнялись.
