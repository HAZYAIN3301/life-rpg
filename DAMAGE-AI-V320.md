## Повреждённые поля

Причина порчи (разрыв многобайтовых букв, 03.09) давно закрыта, но потерянные буквы не
восстанавливались: целых копий нет. Теперь в плашке — **«Исправить с помощью ИИ»**:

1. ИИ получает **только фрагменты** по ~60 знаков вокруг «�», не весь текст (под кнопкой строка:
   «Фрагменты с «�» увидит ИИ-сервис»). Вызов — через общий механизм ИИ (отмена, таймаут 60 с).
2. Предложение принимается, **только если оно заполняет дыры и не меняет больше ни одного символа**:
   каждая серия из N «�» → 1…N символов, весь остальной текст символ в символ
   (`DamageRepairV1.restorationValid`). Иначе место остаётся «поправь вручную».
3. Человек видит **«было → стало»** и жмёт «Применить» (или «Отмена»).
4. Сервер (`/api/account/repair-damage`, поле `restorations`) **проверяет каждую замену снова**:
   тот же файл аккаунта, та же испорченная строка на том же месте, честное заполнение — и пишет
   тем же путём, что восстановление из копий (бэкап/WAL для пары settings+tasks). Секретные и
   чужие файлы недоступны; повтор безвреден.
5. После записи приложение перечитывает данные; если порчи не осталось — плашки нет.

Проверено: тесты модуля (+3) и сервера (новый `damage-restoration-server-v1.test.js`: честная
замена записана, лишняя правка/неповреждённое место/секретный файл — нет, повтор безвреден);
браузер WebKit и Chromium, iPhone-профиль, ИИ подменён: ушли 3 фрагмента 26/107/66 знаков,
предпросмотр, «Применить» → «Исправлено: 3», плашка исчезла. Полный набор 3272/3272.
**Не проверено:** настоящий ИИ на настоящих данных владельца — качество догадки зависит от модели;
предпросмотр для того и нужен.
