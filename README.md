# Life-RPG

Личный геймифицированный планировщик жизни. Соединяет RPG-механику (опыт, уровни, навыки)
с планированием дня в духе Sunsama, плюс статистика по жизни. Локально, без подписок,
**данные — обычные JSON-файлы в твоём Obsidian-vault** (папка `data/`), поэтому сервис не может «пропасть».

## Как запустить

**Просто:** двойной клик по `Запустить.command` (откроет браузер и поднимет сервер).

**Из терминала:**

```sh
cd "life-rpg"
npm start          # → http://127.0.0.1:4317
```

Зависимостей нет — `npm install` не нужен. Достаточно установленного Node.js.

## С телефона/планшета (потом)

Данные уже синхронизируются вместе с vault (Obsidian Sync / iCloud), так что они и так на телефоне.
Чтобы открыть сам интерфейс с телефона в той же Wi-Fi сети:

```sh
npm run lan        # сервер слушает всю сеть (HOST=0.0.0.0)
```

затем на телефоне открой `http://<IP-мака>:4317`. Дальше планируются два пути:
плагин Obsidian (работает на Obsidian-мобайл) и постоянный сервер.

## Данные

- `data/settings.json` — навыки/сферы жизни, формула XP, кривая уровней.
- `data/tasks.json` — все задачи (источник правды; опыт и статистика считаются из них).
- `data/days.json` — рефлексия и статус «день закрыт» по датам.

Это твои файлы. Бэкап = бэкап vault. Можно открывать и править в любом редакторе.

## Архитектура

- `server.js` — Node stdlib, отдаёт фронтенд + REST на чтение/запись `data/*.json`.
- `public/` — фронтенд на чистом JS, без сборки и без библиотек (графики — рисованный SVG).

Ноль внешних зависимостей сознательно: нечему ломаться или «протухать».
