# Inspiration — решение владельца 03.10, v323

Для первого выпуска: личные материалы пользователя и свои/лицензированные материалы
общей подборки. TikTok открывается вне Satoru. Это принятое решение, не вопрос на согласование.

## Реализовано

- Общая подборка требует явного вида лицензии: satoru-original, public-domain, CC,
  licensed-direct. `official-source` или разрешённый iframe сами по себе недостаточны.
  Прежние проверки доступности, языка и воспроизведения остаются обязательными.
- Автопоиск Inspiration отключён и в клиенте, и на сервере, даже при сохранённом opt-in
  и настроенном ключе. Поиск Доски не меняется. Старые находки не обходят проверку лицензии.
- TikTok не создаёт iframe и не загружает обложку: включая старые карточки, ссылки
  vm/vt.tiktok.com и поддельно переданный embed без sourceUrl. Плеер проверяет сам,
  поэтому permissive legacy callback не обходит запрет.
- Личные ссылки, подписи, вкус, старый opt-in, история и отметки дня не удаляются.
  Недопущенный материал исчезает из общей выдачи без подмены другим в уже сохранённом дне.
  Это изменение допуска выдачи, не миграция пользовательских данных.
- «Открыть источник» проходит существующее окно внимания. Переход только после
  подтверждённого сохранения. В оболочке используется обычная ссылка через native delegate;
  в браузере — переход с возможностью вернуться назад. Просмотр не начисляет золото/XP.
- Новые надписи короткие и переведены на пять языков. Опция поиска скрыта.

## Проверки и пределы

Chromium и WebKit: 40 сочетаний языка/ширины/темы с reduced motion; сохранение референса
через сервер → reload → внешний маршрут, без запросов к TikTok. Unit/integration:
отказ/повтор записи, старые карточки, явные лицензии, неизменность completion receipts,
отсутствие поиска и изменений старого cache. Проверки отключённого discovery-движка
сохранены отдельно от тестов реально выключенной конфигурации.

Логи: work/inspiration-release-20261003/. Полный suite 3279/3279; node --check,
git diff --check и offline shell PASS. Production receipt — во внешнем CHECKPOINT.
Физическое открытие TikTok в build 10 на iPhone/Mac ещё не проверено.
Unsigned archives build 10 сами по себе не являются обновлением TestFlight.

## Для Apple

Reviewer notes: “Inspiration contains personal saved links and an admitted catalog of
owned/licensed materials. TikTok opens externally after a bounded attention session;
there is no embedded TikTok player or TikTok poster in the app. Automatic public-web
discovery is disabled for this release. Saved personal links remain private to the account.”

Pinterest/YouTube из личных ссылок по-прежнему могут связываться со своими провайдерами.
Явный импорт TikTok-ссылок может запрашивать метаданные через сервер; автоматическое
обогащение TikTok-референса при сохранении настройки отключено. Поэтому этот выпуск
не доказывает глобальное tracking=false. Политика на пяти языках отражает это различие.
Владелец подтверждает права, итоговую privacy/age/trader-анкету и отправляет выбранную сборку.
Обновление настоящих native-скриншотов остаётся после подписанной сборки/device QA.
