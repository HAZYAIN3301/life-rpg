# Визуальный лист персонажей v1

Две версии одного и того же листа.

| Файл | Когда нужен |
|---|---|
| `index.html` | открывать **отсюда, с диска**. Лёгкий: тянет картинки из `public/art` по относительным путям. Всегда показывает актуальные ассеты. |
| `visual-sheet-portable.html` | когда лист надо **переслать или открыть с телефона**. Картинки уменьшены до размера показа и вшиты внутрь, поэтому файл работает где угодно. Не хранится в git — собирается командой ниже. |

```sh
sh design-lab/character-visual-sheet-v1/build-portable.sh
```

Скрипт не трогает оригиналы: он делает уменьшенные копии во временной папке, вшивает их в
HTML и удаляет копии. Около 3 МБ на выходе против 11 МБ исходников.

Почему две версии, а не одна: файл со ссылками на диск при пересылке показывает пустые
рамки вместо картинок — проверено на телефоне 10.09.
