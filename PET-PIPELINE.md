# Satoru — как создать питомца: от нуля до анимации (полная инструкция)

> Производственная инструкция + контракт paper-doll движка. По ней художница, AI или разработчик делают нового питомца единообразно. Стиль — `STYLE-DECISION.md`. Движок-пилот — `public/paperdoll-demo.html`. Общий арт-путь — `ART-PIPELINE.md`.

**Главный принцип:** питомец — это НЕ картинка и НЕ видео. Это **один SVG, разобранный на именованные слои**. Движок их перекрашивает, надевает экипировку в слоты, анимирует трансформами. Поэтому всё, что мы рисуем, должно быть **разборным**.

---

## Шаг 0. Целевой стиль (зафиксирован)

- **Chibi-аниме**: большая голова/тело, маленькие конечности, крупные выразительные глаза, мягкая округлая форма.
- **Плоский ровный свет** — БЕЗ запечённых теней/градиентов в самом арте. Объём даём 1–2 мягкими слоями (животик светлее, лёгкая тень снизу). Свет/ауру накладывает движок.
- **Толстый чистый контур** (опц.) или без контура, но единообразно по всем питомцам.
- **Ограниченная палитра**, тело — один доминантный цвет (он будет перекрашиваться движком).
- **Силуэт читаемый** в маленьком размере (питомец показывается ~84–210px).
- Фронт или 3/4, поза A (симметричная, конечности от тела — чтобы части не перекрывались и анимировались).

---

## Шаг 1. Получить базовое изображение питомца

**Вариант A — AI-генерация (быстро, основной путь).** Через Satoru-style-model (Scenario) или SDXL со style-ref. Промпт-шаблон:

> chibi anime creature pet, front view, A-pose, big round body, small limbs, large expressive eyes, soft rounded silhouette, [ВИД: напр. «fox spirit» / «slime» / «baby dragon»], [ЦВЕТ] dominant color, flat even lighting no baked shadows, thick clean outline, simple shapes, centered full body, plain white or transparent background, mobile game mascot style matching project style

Генерим несколько, выбираем с **чётким силуэтом и разделимыми частями** (уши/хвост/лапы не слиплись с телом).

**Вариант B — художница рисует** сразу разобранным на слои в Procreate/PSD (см. Шаг 2). Это идеал, но не блокер.

---

## Шаг 2. Разобрать на части (КЛЮЧЕВОЙ шаг)

Питомцу нужны эти части как **отдельные слои/объекты**:

| Часть | id в SVG | Зачем отдельно |
|---|---|---|
| Тень на полу | (без id, статична) | контакт с землёй |
| Аура (прокачка) | `pet-aura` | свечение тира, вкл/выкл |
| Хвост | `pet-tail` | виляет (анимация) |
| Лапы | внутри `pet-body-grp` | — |
| Левое ухо | `pet-ear-l` | подёргивается |
| Правое ухо | `pet-ear-r` | подёргивается (со сдвигом фазы) |
| Тело | внутри `pet-body-grp`, `fill="var(--pet-body)"` | перекраска |
| Животик | внутри `pet-body-grp` | объём (светлее тела) |
| Глаза (группа) | `pet-eyes` | моргание |
| Румянец/рот | внутри `pet-body-grp` | мимика |

- Если из AI-картинки: убрать фон (как с Тенью — кей/матирование), затем **вырезать части** (в редакторе по слоям) ИЛИ перерисовать части по образцу.
- Если рисует художница: каждая часть — свой слой, на прозрачном фоне, в **единой системе координат** (части не сдвинуты — собираются стопкой как есть).

---

## Шаг 3. Подготовить SVG (контракт движка)

Собрать части в **один SVG** `viewBox="0 0 200 220"` (или свой, но фиксируем на серию), порядок отрисовки снизу вверх: тень → аура → хвост → группа тела → слоты.

**Обязательные правила:**
1. **Перекраска:** все слои основного цвета тела → `fill="var(--pet-body, #8a6cff)"`. Животик/детали — отдельные фикс-цвета или `color-mix`.
2. **id частей** — ровно как в таблице Шага 2 (движок ищет их для анимации).
3. **Группа тела** `<g id="pet-body-grp">` оборачивает всё, что должно качаться вместе (тело, уши, лицо, лапы).
4. **Слоты экипировки** — пустые группы с якорем-трансформом:
   - `<g id="slot-head" transform="translate(100,74)">` — поверх всего (шапки).
   - `<g id="slot-neck" transform="translate(100,170)">` — на шее (ошейник/шарф).
   - `<g id="slot-back" transform="translate(140,118)">` — за телом (накидка/крылья).
   - Координаты слота = точка привязки предмета на ЭТОМ питомце (у разных питомцев разные).

Если части растровые (PNG) — допустимо вставлять `<image>` в те же id-группы; перекраска тогда через CSS-фильтры (хуже) или красить варианты заранее. **Вектор предпочтительнее** (чистая перекраска + резкость на любом размере).

## Шаг 4. Зарегистрировать питомца в движке

Движок хранит питомцев как данные. Формат записи (в `PETS` реестре):

```js
PETS['fox'] = {
  name: 'Лисёнок',
  viewBox: '0 0 200 220',
  svg: `<...слои с id, см. Шаг 3...>`,   // или путь к .svg файлу
  slots: { head:[100,74], neck:[100,170], back:[140,118] }, // якоря именно этого питомца
  tiers: [ {at:0}, {at:6,aura:true}, {at:20,aura:true,crown:true} ], // прокачка
};
```

Добавить нового = добавить запись. Всё остальное (рендер, перекраска, анимация, слоты) движок делает сам.

---

## Шаг 5. Анимация — автоматическая

Idle-анимация **не рисуется покадрово** — движок применяет CSS к частям по id:
- `pet-body-grp` — покачивание (дыхание),
- `pet-ear-l/-r` — подёргивание ушей (фазовый сдвиг),
- `pet-tail` — виляние,
- `pet-eyes` — моргание,
- `pet-aura` — пульсация свечения.

Поэтому **достаточно назвать части правильными id** — анимация включится сама. Доп. состояния (happy/sleep) = свои CSS-классы на группе (по желанию). `prefers-reduced-motion` отключает анимацию.

---

## Шаг 6. Экипировка (артефакты/награды на питомце)

Предмет = маленький SVG **в локальных координатах слота** (0,0 = якорь слота):

```js
ITEMS['hat'] = `<g transform="translate(0,-2)">...<path .../></g>`;
```

Надевание: `equip(petEl, 'head', 'hat')` вставляет SVG предмета в `slot-head`. Снятие — очистка группы. Предмет рисуется в стиле питомца (chibi, плоский свет). Один предмет можно подогнать под разные слоты-якоря разных питомцев — геометрия предмета не меняется, меняется только трансформ слота.

## Чек-лист приёмки нового питомца

- [ ] Стиль = chibi, плоский свет, читаемый силуэт (Шаг 0).
- [ ] Части разделены и названы правильными id (Шаг 2–3).
- [ ] Тело красится через `--pet-body` (проверить сменой цвета).
- [ ] 3 слота-якоря заданы под этого питомца; шапка/шарф/накидка садятся ровно.
- [ ] Idle-анимация играет (уши/хвост/моргание/качание).
- [ ] Хорошо смотрится на 84px и на 210px, на тёмной и светлой теме.
- [ ] Запись в `PETS` добавлена; рендерится в разделе «Питомцы».

---

## TL;DR пайплайн

1. Сгенерь/нарисуй chibi-питомца (плоский свет, разделимые части).
2. Разбери на части → назови id по таблице.
3. Собери в один SVG, тело → `var(--pet-body)`, добавь 3 слота-якоря.
4. Добавь запись в `PETS`.
5. Анимация и перекраска включаются сами; экипировка — SVG в слот.

Образец, реализующий всё это — `public/paperdoll-demo.html` (питомец-дух). Копируй его структуру для новых.
