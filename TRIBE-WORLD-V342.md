# Племя: игровой вход — v342

## Было → стало

Страница из нескольких игровых модулей → карта с шестью местами. Нажатие ведёт
маленького персонажа к зданию и открывает только его содержимое. На карте одна строка
подсказки; участники и приватность находятся в «Друзьях».

| Место | Действие |
|---|---|
| Логово | Личная комната и мебель |
| Общий дом | Обстановка компании, трофеи, раскрываемое строительство |
| Казарма | Совместное дело с другом |
| Лес | Вылазка, вклад из дела/привычки/фокуса |
| Пещера | Испытания стража после первой вылазки |
| Арена | Недельный рейд, награда, сезон и рейтинг |

Карта доступна без компании, общие действия сохраняют создание/вступление и согласие.
Уровень открытия Племени не изменён. Личные данные не добавлены к публичному составу.
Прямой вход из «Сегодня» ведёт к нужному действию; строительство сразу раскрывается.

## Контракт

`party-world-ui-v1.js` отвечает за геометрию, локализацию, маршрут и отмену переходов.
Scope: аккаунт + Store epoch + подтверждённая компания. Временный null при загрузке
не равен выходу. Последний клик побеждает, возврат/смена контекста отменяет старый callback.
В reduced motion переход мгновенный; DOM-кнопки доступны с клавиатуры.
После перезагрузки старт — карта. Перемещение по меню не даёт XP/золото и не вызывает
серверный вклад. API и схемы экономики не изменены; все записи остаются за прежними модулями.

Отдельные карта и две миниатюры описаны в `public/art/party-world-v1/PROVENANCE.md`.
Это анимированная навигация по местам, а не свободное управление или новая система аватара.
