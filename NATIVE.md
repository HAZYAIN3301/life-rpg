# Gojo как настоящее приложение (без сторов где можно)

Честная карта: **что реально установить «из интернета», а что упирается в правила платформ.** Gojo — это веб-приложение на Railway + полноценный PWA, поэтому база для всех обёрток уже готова (манифест, сервис-воркер, офлайн, иконка-«?», пуши).

| Платформа | «Скачать с сайта и поставить»? | Как |
|---|---|---|
| **Android** | ✅ Да, `.apk` | PWABuilder → подписанный APK, кладём на сайт ссылкой |
| **Mac** | ✅ Да, `.app`/`.dmg` мимо стора | PWA-install в Chrome/Edge ИЛИ Tauri/Electron-сборка |
| **Windows** | ✅ Да, `.exe`/`.msix` | PWABuilder (готовый пакет) |
| **iPhone / iPad** | ⚠️ Только PWA «На экран Домой» | Apple **запрещает** сайдлоад. Нативный `.ipa` = App Store / TestFlight |

> **Главное:** на iOS/iPadOS «приложение, скачиваемое с сайта» в обход App Store **невозможно** — это стена Apple, не наша. Наш ответ на iOS — PWA «Поделиться → На экран Домой» (уже работает: иконка, полный экран, офлайн, пуши на iOS 16.4+). Настоящий нативный iOS-апп = только Xcode + Apple Developer ($99/год) + App Store (или TestFlight для теста).

## 📱 Android — `.apk` для скачивания с сайта (рекомендую PWABuilder)
1. Открой **pwabuilder.com**, введи URL Gojo (`https://…railway.app`). Он прочитает наш манифест/иконку.
2. Вкладка **Android → Generate Package**. Тип: «Signed APK» (или App Bundle для Play).
3. Первый раз он создаст **ключ подписи** — **сохрани его** (`signing.keystore` + пароли): им подписываются все будущие обновления. Положи в надёжное место (не в гит!).
4. Скачаешь `.apk` → залей куда угодно (хоть отдай файлом, хоть ссылкой на сайте). На телефоне: открыть → «Установить» (разрешить установку из этого источника).
5. APK — это TWA (Trusted Web Activity): тонкая обёртка, которая открывает наш сайт в полноэкранном режиме. Контент обновляется сам (это наш Railway), пересобирать APK нужно только при смене иконки/имени.

*(Альтернатива — CI: можно добавить GitHub Actions + Bubblewrap, чтобы APK собирался автоматически при пуше. Отложено: PWABuilder проще и надёжнее для старта.)*

## 💻 Mac — настоящее приложение
- **Быстро (0 минут):** открой Gojo в **Chrome/Edge на Mac** → меню → «Установить Gojo». Появится отдельное приложение в Launchpad/Applications, своя иконка, без вкладок браузера. Это уже «приложение-приложение».
- **Дистрибутив `.dmg` (чтобы раздавать):** обёртка через **Tauri** (рекомендую — лёгкая, ~3 МБ) или Electron. На твоём Mac:
  1. `npm create tauri-app` (или Electron), указать `build.devUrl`/окно на наш Railway URL (тонкий WKWebView-шелл).
  2. `npm run tauri build` → получишь `.app` и `.dmg` в `src-tauri/target/release/bundle/`.
  3. Раздаёшь `.dmg`. Для запуска без предупреждений Gatekeeper — нужна нотаризация (Apple Developer $99), без неё ставится через «ПКМ → Открыть».

## 📲 iPhone / iPad
- **Сейчас (без стора):** Safari → Поделиться → **«На экран Домой»**. Полноценное приложение: иконка-«?», полный экран, офлайн, пуши (после установки, iOS 16.4+). Это рабочий путь для тебя и друзей прямо сейчас.
- **Нативный `.ipa` (если захочешь в App Store):** PWABuilder → iOS package, либо Capacitor (`npx cap add ios`) → открыть в **Xcode**. Дальше: для себя — бесплатная подпись Xcode (переподписывать раз в 7 дней); для других — нужен **Apple Developer ($99/год)** и публикация в App Store / TestFlight. Сайдлоад «с сайта» Apple не разрешает (кроме альт-сторов в ЕС).

## Что уже сделано в коде (фундамент)
- Манифест (`manifest.webmanifest`): standalone, иконки PNG 192/512 + maskable + SVG, тема/фон.
- Сервис-воркер (`sw.js`): офлайн app-shell (network-first), push + notificationclick.
- Иконка: фирменный **«?»** (`icon.svg` + `icon-192/512.png`, `apple-touch-icon.png`; генератор `scripts/gen-icons.js`).
- Install-баннер в приложении (Android/десктоп — кнопка, iOS — инструкция).
- Web Push (VAPID, zero-dep) — подписка/тест в Настройках.

**Вывод:** «приложение, скачиваемое из интернета» = **готово для Android (.apk через PWABuilder) и Mac (PWA-install / .dmg-обёртка)**; на iPhone/iPad — PWA на экран Домой (нативное вне App Store невозможно по правилам Apple).
