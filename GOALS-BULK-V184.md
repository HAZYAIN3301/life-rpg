# Goals bulk management v184

## Почему этот релиз появился

После редизайна Goals исчез видимый путь для изменения нескольких целей, а Тень умела предложить не больше пяти одиночных действий. Запрос «архивируй всё ниже уровня Путь» поэтому закончился обрывком внутренней инструкции модели вместо понятного preview.

## Контракт

- В `Все цели` есть режим `Выбрать несколько`: отдельная 42 px кнопка выбора у каждой видимой цели, `Выбрать все видимые`, пауза, архив и удаление.
- Пауза и архив выполняются одной проверенной транзакцией `goals/tasks/groups`; при ошибке серверной записи UI не сообщает успех и исходные данные остаются в State.
- Удаление по-прежнему не является командой ассистента. В ручном интерфейсе оно проходит через существующий destructive dialog с описанием дочерних целей и связанных квестов.
- Тень получила только обратимые массовые команды `goal_pause_many` и `goal_archive_many`. Они принимают до 100 точных собственных `targetIds`; если хотя бы один id не существует, не применяется ничего.
- Контекст Тени теперь содержит горизонт каждой цели. Канонический порядок: `mission → vision → path → long → mid → short → recurring`; «ниже path» означает последние четыре уровня.
- Внутренний action-contract и повреждённый ответ провайдера не показываются как реплика чата. Пользователь получает короткое локализованное сообщение и может повторить запрос.

## Исправление `��`

`httpsPostJson()` раньше неявно декодировал каждый сетевой chunk отдельно. Если многобайтовая кириллическая буква была разрезана TCP-границей, две половины превращались в U+FFFD. Теперь ответ сначала собирается как bytes через `Buffer.concat`, затем один раз декодируется как UTF-8.
