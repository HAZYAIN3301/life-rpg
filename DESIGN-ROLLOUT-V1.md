# Полный перенос редизайна — 08.09.2026

## Поручение и полномочия

После просмотра связного Today/Plan Альберт разрешил редизайн остальных частей и перенос
в настоящее приложение. Предыдущий gate «только preview» снят этим запросом, не задним
числом. Условие: сохранить старую версию в облаке для сравнения. Просьба экономить
недельный лимит: общие компоненты, без новой фабрики арта/вариантов, повторного широкого
чтения и параллельных агентов.

## Две версии, одни рабочие данные

- Новая: существующий production Satoru, реальные State/Store/CAS/WAL. Не модель
  из design-lab. Текущие аватар, питомцы, инвентарь, экономика сохраняются.
- Старая: /compare.html → frozen /design-baseline/v244/index.html.
  Снимок от 74a97ddbef6547e482b6b6944a10d377b8db604e, до переноса.
  94 старых script/style + исходный шрифт; исходные SHA-256 в manifest.
  Отличия: вместо auth/init только synthetic read-only boot, абсолютные пути frozen
  code, guard + sandbox. Датированный public art переиспользован.
- Архив НЕ копия личного аккаунта и НЕ вторая writable ветка базы. Для критики
  расположения и внешнего вида; селекторы 16 экранов и light/dark. Это предположение
  явно сообщено пользователю до реализации. Его данные/медиа не копировались.
- CSP sandbox без allow-same-origin, connect-src none, form-action none; отключены
  камера/микрофон/geolocation. JS guard — дополнительная защита, не единственная.
- Не исправлять frozen бизнес-логику и не перезаписывать baseline новой сборкой.
  Новый снимок требует нового каталога. Git baseline сохраняет точные исходники.

## Визуальный контракт

Russo One для крупных заголовков, спокойные светлая/тёмная темы, округлённые формы,
фиолетовая Тень и существующие изображения. Не Times/книжный стиль; не неоновый cyan;
не новый 3D-манекен. Сначала дела. Тень — поддержка, не обязательная рефлексия.
Телефон: Today/Plan/Habits/Hero/More. Тематические семьи позже.
