# Решения владельца — коротко для телефона

**Ответы получены 12.09.** Push/deploy разрешены ранее и не требуют нового согласия.

**1. Прогресс — пояснение**

Вопрос был о разнице между твоими записями и серверными наградами. Архив по-прежнему
переносит личный XP, золото и предметы. Новую ограничительную политику ты не выбирал,
поэтому она не введена. Подтверждения уже выданных серверных наград хранятся отдельно:
импорт старого архива не выдаёт те же сундуки второй раз.
**На этот пункт сейчас отвечать не нужно.**

**2. Расширение — Chrome и Brave. Принято.**

Готова версия 0.6.0, проверена реальная граница в обоих браузерах, собран пакет
Chrome Web Store. В Brave используется тот же магазин. Это ещё не store-публикация.

**3. Характер Тени — да. Принято.**

Короткая конкретная помощь; глубина по запросу; обоснованное несогласие;
без догадок об усталости и стыда. Решение остаётся за человеком. Текстовый
характер подключён. Приёмка изображений и пауза аватара/Rest Profile не менялись.
