# Три решения — можно ответить с телефона

Можно одной строкой: **1А, 2А, 3А**. Ответы ещё не получены.
Технические исправления, push и deploy выполняются по уже данному разрешению.

**1. Перенос прогресса через архив**

Сейчас архив переносит XP, золото и предметы. Какой принцип сохраняем дальше?

- **А.** Свободно переносить личный прогресс; подтверждённые сервером награды защищать отдельно.
- **Б.** Переносить записи, а новые игровые права выдавать только по серверным подтверждениям.

Это выбор следующего этапа экономики. v259 не меняет прежние права и суммы.

**2. Где сначала публиковать расширение?**

- **А.** Chrome Web Store.
- **Б.** Firefox Add-ons.
- **В.** Пока только скачивание ZIP.

**3. Принимаем основу характера Тени?**

Тень сама предлагает короткую конкретную помощь. Развёрнутый разговор — по запросу.
Может обоснованно не согласиться. Не угадывает усталость и не стыдит.
Последнее решение всегда за человеком.

- **А.** Да, принять эту текстовую основу.
- **Б.** Нужны изменения — написать, какие.

Это решение о характере и текстах, а не художественная приёмка изображений.
Пауза аватара и Rest Profile сохраняется; отдельного ответа об их возобновлении
для текущего технического этапа не требуется.
