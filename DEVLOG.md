## [2026-07-01] ⚖️ Две системы дисциплины «Доверие vs Контроль» v1 — фидбек fb_mqvdlowgjx6s
Самая мощная нереализованная идея из `FEEDBACK-ANALYSIS.md` #1. Спроектировано после ресёрча faction-игр (Fortnite Showdown, Pokémon GO, Splatfest, Ingress), karma-систем (Fable/inFamous/Mass Effect) и commitment-девайсов (StickK/Beeminder, Habitica-баг, Duolingo-антипаттерн) — весь разбор в `DISCIPLINE-PATHS-PLAN.md`. Реализованы все 5 фаз плана.

**Философский гейт (главное):** Контроль строго opt-in, с мгновенным беспоследственным выходом (асимметрия входа/выхода как у `anti-unslip`). Штрафы строго персональные — НИКОГДА по пати (урок бага Habitica). 4-я стена заглушаема тумблером (урок Duolingo). Факции РАВНЫ по силе — Контроль не даёт больше наград за тот же труд (урок Ingress/Pokémon GO). Всё это защищает бренд «через любовь не вину» (`ALTERNEYT.md`).

- **Данные** (`app.js` DEFAULT_SETTINGS): `path: null|'trust'|'control'` (null = ещё не выбран, поведенчески = тёплый Доверие → существующие юзеры не ломаются), `pathChosenAt`, `pathAntagonistMuted`, `systemSkinOff`, `control.lastReckon`, `pathTeaserAt`. Конфиг `PATHS` (Тень/Кремень, глиф, тег, питч), `CONTROL` (штраф −5 энергии/дедлайн, кап −15/сутки). Хелперы `currentPath/pathChosen/pathInfo/pathStreakGrace`.
- **Механики Контроля vs Доверия:**
  - *Серия строже:* `pathStreakGrace()` — явный Доверие даёт +1 базовое прощение (доброта), Контроль/не-выбравшие = только перк-щит (как было, 0 сюрприза существующим). Привычки: `habitStreak` baseFreeze 0 при Контроле, 1 иначе.
  - *Расчёт пропусков:* `pathReckoning()` (вызов в `render()`, гард `lastReckon===today`) — пропущенные дедлайны в окне (prev..today) бьют по энергии, каждый дедлайн заряжается ОДНОКРАТНО (не компаундится — анти-Habitica-спайк), суммарно ≤ кап. Первый день в Контроле не наказывается задним числом (якорь lastReckon=today при выборе). Прозрачный тост «ты выбрал этот путь», без стыда.
  - *Авто-скин:* `applyTheme` при `path==='control'` форсит скин «Система» v2 (готовый с 2026-06-20), если не включён оверрайд `systemSkinOff`. Ставит `data-path` на `<html>`.
- **Экран выбора** `showPathChoiceModal()` — двухкарточный (Тень vs Кремень, каждый питчит философию, «правильного» ответа нет). Заходит дрип-триггером `d_path` (расширил `dripSeen`/`dripStart` под `modal:'path'`), условие: `tutDoneOrSkipped() && charLevel()>=3 && !pathChosen()` — не спрашиваем вслепую (урок Pokémon GO: сначала пойми игру). `choosePath()` мгновенно, без охлаждения.
- **Настройки** `pathCard()` — выбор/смена стороны + тумблеры Контроля (скин-оверрайд, mute антагониста). Действия `set-path`/`toggle-system-skin-off`/`toggle-antagonist-mute`.
- **Антагонист-маскот Кремень** — черновой inline-SVG `flintMascotSVG()` (кристаллический скол-«лицо», циан-градиент) — плейсхолдер до арта Виолы (тот же paper-doll пайплайн). 4-я стена: `pathTeaserCard()` на «Сегодня» — реплика ПРОТИВОПОЛОЖНОГО маскота манит к себе (≤1/нед по `pathTeaserAt`, кнопки Перейти/Остаться/Не звать), заглушаемо. `PATH_TEASERS` по текущей стороне.
- **Командный слой:** `path` в payload `publishLeaderboard` + `server.js` (`user.pub.path`, некомпетитивно как `clean`) + отдаётся в строках лидерборда (+weekXp). Табло `pathBannerHTML()` (Splatfest-стиль): при ≥3 активных с КАЖДОЙ стороны — агрегированный бар вклада за неделю; иначе честный fallback «твой личный вклад» (не выдумываем командную статистику на малом масштабе). Глиф пути в каждой строке рейтинга.

**Проблема v1:** ручная обёртка `t('строка')` по коду пропустила ~90% UI (≈1300 строковых литералов) — переводились только тронутые места. Скриншоты юзера показали почти сплошной русский в DE.

**Решение — пост-рендер DOM-проход (единый источник правды = словарь):**
- `translateDOM(root)` вызывается в конце `render()`; обходит текст-узлы + `placeholder/title/aria-label`, переводит по словарю. Узлы с кириллицей, не внутри `[data-noi18n]` (юзер-контент — переключатель языков). Авто-чинит и nav из `index.html`, и динамически добавленные модалки/тосты — через `MutationObserver` на `document.body` (`startI18nObserver`).
- `i18nString(s, l)`: 1) точный збіг по словарю → 2) `I18N_DYN` динамические шаблоны → 3) emoji-префиксный фолбек (`i18nWord`: «🌱 Новичок» → «🌱 Neuling») → 4) inline-токены `ур.N`→`St.N/lv.N/...` и единицы `Nм/Nч`→`Nm/Nh` (применяются ПОВЕРХ перевода, чтобы composе работало).
- `I18N_DYN` — ~20 regex-шаблонов для интерполированных строк: стрик-фразы компаньона, `связь N/M → Tier`, `N заметок — открыть`, `Ещё N до сундука`, `N/M собрано`, даты `21 июня`, `Неделя 15.06 – 21.06`, gear-бонусы, обобщённый разделитель ` · ` (переводит каждую часть), `A (N)` и др. Множинні форми (день/нотатка) — `i18nDay/i18nNote` по правилам каждого языка.

**Словари:** комбинированная таблица `I18N_EXTRA` (`ru → {en,de,uk,es}`) для новых строк + сохранены/расширены `I18N_EN/DE`, добавлены `I18N_UK/ES`. Слиты в `I18N = {en,de,uk,es}`. `t(k)` теперь читает `I18N[lang()]`. Покрыто ~350 строк: вся навигация, шапка/профиль, компаньон (Тень/реплики/тиры связи), прогресс-трио, Сегодня, Цели (типы/хинты), Привычки (+весь метод «Атомные привычки»), Награды (лутбокс/коллекция/арсенал/гир), 40 ачивок (title+desc), ранги, рарности, косметика, архетипы, энергия/форма, Статистика, Неделя, Календарь (дни/месяцы/режимы), Настройки-чром, тосты.

**Переключатель:** 5 кнопок 🇷🇺/🇬🇧/🇩🇪/🇺🇦/🇪🇸 (Настройки, `set-lang`). Sphere-имена и квест-тексты НЕ переводятся (это юзер-контент) — намеренно.

**Дополнено до полного покрытия (2026-06-21, та же сессия):** Питомцы/Зверинец, анти-привычки, каталог наград (33 пресета), программы-данжи (имена+таглайны+сферы), вся карточка Настроек (подписка, безопасность, admin, AI-keys гид, focus/Помодоро, кривая уровней, импорт-карта с образоват. лестницами), все плейсхолдеры, дефолтные имена сфер (Здоровье/Заработок/Учёба→Gesundheit/…). Новые шаблоны: рекурсивные роздільники ` · ` и `, ` (перекладають кожну частину через i18nString — тому «N прив.» теж), `Внутри «X»`, `Вставь ключ (X)`, day-summary, pet-missing-days, «N прив./квест.». **Проверено в превью: 0 непереведённых chrome-строк во ВСЕХ видах (today/rewards/goals/character/stats/calendar/weekly/settings/pets/skills/progress/party/leaderboard + все саб-табы привычек) на DE; EN/UK/ES — корректны.** Языковые имена (🇷🇺 Русский и т.д.) намеренно НЕ переводятся (`[data-noi18n]`).
