Install in Chrome

  1. 1

    Download and unzip

    The archive contains a ready extension folder.

    Download package
  2. 2

    Open the extensions page

    Paste this address into the browser bar.

    chrome://extensions
  3. 3

    Load the folder

    Enable Developer mode, choose Load unpacked and select the unzipped Satoru Attention folder.

Why the test build still needs ReloadConsumer browsers only auto-update signed store installations. The packages above are ready for review; store accounts and signatures are the remaining publication step.
