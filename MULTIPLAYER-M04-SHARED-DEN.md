# M04A — настоящее общее Логово, v311

28.09.2026. Следующий шаг после отрицательной продуктовой приёмки отдельной головоломки M01.
Это live-функция существующего приложения, не новый экспериментальный URL.

## Пользовательский маршрут

1. Награды → «Тихий вечер» → выбрать вещь и сохранить цель накопления.
2. Цель видна в «Сегодня»: сколько золота осталось, ограничение уровня или возможность покупки.
3. Обычное дело/привычка приносит свою прежнюю награду. Нового кошелька и повторного начисления нет.
4. Примерка → покупка через существующего владельца экономики. Вещь появляется в личном Логове.
5. Племя → существующая пати → «Общее Логово». Выбрать принадлежащую себе вещь и явно поставить её для группы.
6. Друг видит комнату, имя владельца вещи и может добавить свою. Обновление каждые 15 секунд
   при открытой вкладке Племени; есть ручное обновление. Во время выбора и неподтверждённой записи редактор не заменяется опросом.
7. Из личного Логова и примерки купленной мебели можно перейти к общей комнате; из неё — к коллекции или личному Логову.

Можно начать с бесплатной стартовой мебели. Не требуются новый уровень, покупка или прохождение
головоломки. Само размещение не приносит XP/золото и не меняет персональный инвентарь.

## Владение и приватность

Одна комната на существующую группу, семь фиксированных мест. Место заменяет/освобождает только
тот, кто поставил вещь. Создатель группы тоже не может перезаписать чужую вещь. Видны только
выбранный предмет, имя участника и время размещения в API; задачи, баланс, весь инвентарь и личное
Логово не передаются. Кнопка размещения сопровождается пояснением видимости, request требует `share:true`.

Это совместное **отображение лично принадлежащих вещей**, не передача собственности и не общий
банк. Выход убирает вещи вышедшего из общей сцены; его личные покупки остаются. При удалении
аккаунта удаляются его размещения и квитанции. Повторное вступление не восстанавливает старое размещение.
Удаление группы удаляет её комнату. Отказ от недельного XP не меняет отдельно выбранную мебель.
Только Free/start-каталог; правила Pro не изменены. Личные зоны и свободное перетаскивание ещё не сделаны.

## Технический контракт

- `server-party-den-v1.js`: чистые validate/view/change/depart. Состояние `party.sharedDen` версии 1.
- `GET/POST /api/party/den`: авторизация своей живой учётной записи и актуального членства.
- POST: ровно `partyId, operationId, revision, share, slot, itemId`; JSON ≤ 2048 bytes; same-origin.
- Сервер проверяет сохранённый личный инвентарь после восстановления журнала экономики.
- CAS всей комнаты. Чужое место и устаревшая ревизия → 409; неподтверждённое владение → 403.
- Одно синхронное изменение после чтения тела; текущая инфраструктура — один Node writer.
- Сохранение тем же durable writer `parties.json` (fsync/rename/fsync directory). Успех после записи.
- Последние 100 operation receipts ограничивают рост файла. Повтор точного запроса возвращает
  текущую сцену без повторного изменения; изменение тела с тем же id отклоняется. После вытеснения
  квитанции старая ревизия остаётся конфликтной, а не воспроизводит старую команду.
- Выход включён в существующий журнал membership/adventure. Account deletion сохраняет прежние
  ограничения общего account owner; не объявляем его полностью crash-atomic.
- Проекция не отдаёт receipts. Повреждённый файл не превращается в пустую комнату.
- Ответ потерян: UI сохраняет тот же запрос для повтора, не показывает оптимистический успех.
  При reload читается серверная сцена. Новая сессия/группа не получает старый UI request.
- Новые UI JS/CSS входят в SW SHELL. API остаётся online-only.

## Граница результата и следующий gate

Это M04A и связность с G02, **не весь M04/M05 и не готовый лучший multiplayer**. Нет нового общего
сюжета, группового рецепта, свободной расстановки, генератора мебели, премиального магазина,
подарков/общего кошелька или переработанного аватара. Цены и источники золота прежние.

M01 не принят владельцем. Этот маршрут проверяет новую продуктовую гипотезу: собственные
полезные действия → желанная вещь → видимый результат рядом с другом. Тесты сохранения
не доказывают желание возвращаться. Прежде чем расширять ассортимент/строить следующий
большой игровой слой, показать владельцу live-комнату; затем выбрать акцент:
персональные уголки/самовыражение либо общая меняющаяся локация/совместные проекты.
Рекомендация — общая меняющаяся локация, с сохранением личного владения.

G03 (использование личных наград), проверка баланса M00/G04, M04B (личные зоны/памятный предмет),
M05 и пилот остаются открытыми. Монетизация требует отдельного решения владельца и документов.
