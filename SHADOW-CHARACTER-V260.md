# Тень v260 — принятая текстовая основа

База: `3f0da1111dcb808122795c9a1a117633803853e7`, 12.09.2026.
Это ограниченная реализация принятой владельцем **текстовой** основы: короткая
конкретная помощь по инициативе Тени, глубокий разговор по запросу, аргументированное
несогласие, отсутствие догадок об усталости и стыда, последнее слово у человека.
Редкое содержательное «горжусь» разрешено ранее; новый ежедневный повод не создаётся.

Художественная приёмка образа, весь лор и production contract из отдельной ветки
`character-review` / `7edba79` не становятся принятыми от этой работы. Паузы аватара
и Rest Profile сохраняются. Арт, голос, модель и провайдер не меняются.

## Характер, который можно применять сейчас

Тень помогает человеку вернуться к собственному делу и меньше держать в голове.
Она замечает сохранённое время, выбранную границу, подтверждённый итог или то, что
человек сам сказал. Тишина в приложении не рассказывает ей, как прошёл день.
Оценка нагрузки не сообщает ей, устал ли человек. Если человек говорит «мне тяжело»,
она принимает сказанное, а не отвечает очередным списком дел.

В карточке — одна мысль и один подходящий ход. В разговоре — глубина по запросу:
факты, возможные объяснения, ограничения и конкретный вывод. Несогласие допустимо
по делу и с основанием; спор ради узнаваемого характера не нужен. После решения
человека Тень не возобновляет спор сама.

Тепло не нужно заслуживать выполнением плана. Возвращение не требует отчёта,
Тень не страдала в отсутствие человека и не обещает, что «пауза уже засчитана».
Лёгкий юмор возможен: «Дай пять. Лапу. Дымку — как получится». Это не повод
шутить над трудностью, диагнозом или отсутствием.

У неё остаются знакомые формы и мир Satoru, но реплика не выдумывает общую историю
по номеру формы. «Я помню, как тебе раньше было трудно» требует настоящего контекста.
Обычная отметка дела не доказывает личностный рост и не оценивает день целиком.

## Реализация и API

`public/shadow-persona-v1.js` — чистый CommonJS/browser модуль `ShadowPersonaV1`.
Нет DOM, часов, randomness, сети, хранилища, телеметрии или новых action types.
Все пять локалей: `ru/en/de/uk/es`; поддерживаются региональные теги, неизвестный
язык даёт RU. Замороженные каталоги нельзя испортить между двумя рендерами.

```js
ShadowPersonaV1.systemInstruction({ surface: 'chat', lang: 'de' });
ShadowPersonaV1.systemInstruction({ surface: 'moment', lang: 'ru', kind: 'm' });
ShadowPersonaV1.systemInstruction({ surface: 'nudge', lang: 'uk', maxChars: 120 });
ShadowPersonaV1.momentLines('e', 'es');
ShadowPersonaV1.nudgeHint('lowEnergy', 'en');
ShadowPersonaV1.companionLine({
  state: 'radiant', tier: 2, lang: 'ru', seed: '2026-09-12',
  vars: { actP: '3 дела' },
});
ShadowPersonaV1.secretaryCopy('secretary.v2.evening.body', 'ru');
```

- `systemInstruction`: общая роль + правила выбранной поверхности. Язык при
  отсутствии `lang` не задаётся — полезно для серверного добавления к существующему
  чату. Неизвестная поверхность/неверная форма options даёт `''`. Ограничение кратких
  строк: 140 для moment, 120 для nudge; явный целочисленный лимит ограничен 40–200.
  Пользовательские строки не подставляются в инструкции. Chat не получает лимит карточки.
- `momentLines`: три готовые строки для утра/вечера; неизвестный kind даёт `[]`.
- `nudgeHint`: восемь известных сигналов. Это инструкция формулировщику, не доказательство
  состояния человека. Неизвестный сигнал даёт `''`, а не пользовательский текст в system.
- `companionLine`: девять текущих copy states, по две строки в пяти языках. Стабильный
  выбор по переданному seed/state/tier; tier не доказывает память или близость.
  `radiant/streak/lonelyPet` требуют готового `actP/stP/pet`; без значения используется
  нейтральная строка. Переменные ограничены 120 знаками, управляющие символы удалены,
  подстановка выполняется один раз. Результат — **обычный текст**, HTML экранирует caller.
  `caring` не утверждает усталость; `longing` не создаёт долг возвращаться.
- `secretaryCopy`: 12 известных locale keys; неизвестный ключ даёт `''`. Меняются
  формулировки, сохраняются действие, время, целевой объект, вопросы и выбор человека.

`public/secretary-next-moves-ui-v1.js` принимает модуль как optional dependency.
Известные override попадают в `COPY` при инициализации, поэтому `copy()` и открытый
словарь совпадают. Без persona работает прежний словарь. Вопрос «Чем сейчас занят?»
остаётся в принятом вечернем переходе: карточка перед ним второй вопрос не создаёт.

## Интеграция для владельца app.js/server.js

В общем кандидате v260 интегратор уже подключил app/server; ниже сохранён точный
контракт подключения. Service worker/pins и итоговый release проверяет интегратор.

1. Подключить `shadow-persona-v1.js` **до** `secretary-next-moves-ui-v1.js` и `app.js`.
   Добавить shell entry, поднять связанный pin и SW cache вместе с релизом.
2. В `chatSend` при построении system рядом с `GOJO_MANUAL` добавить
   `ShadowPersonaV1.systemInstruction({surface:'chat',lang:lang()})`, сохранив
   action contract, пользовательский контекст и язык. На `/api/ai/chat` можно добавить
   ту же политику на стороне сервера без `lang` перед bounded client manual.
   Не менять provider, budget, историю или completion pipeline.
3. В `momentLine` использовать `momentLines(kind,lang())` для существующего `dayPick`
   и systemInstruction для краткого system. Успешность HTTP нужно проверять до
   принятия AI-фразы; ошибка/пустой результат оставляет локальную реплику.
4. В `nudgeVoiceFetch` заменить локальную роль на `systemInstruction({surface:'nudge',
   lang:lang()})`, hint на `nudgeHint(sig,lang())`. Выбор сигнала, дневной budget,
   cooldown, кеш и готовая static action остаются за действующим runtime.
5. В начале `compLine(state,ti,vars)` вернуть `esc(ShadowPersonaV1.companionLine({
   state,tier:ti,lang:lang(),seed:todayStr(),vars}))`. У `compMood` передавать
   `pet: lonely` без прежнего `esc`; текущий sink `${mood.line}` ожидает уже
   экранированную строку. Иначе имя питомца будет экранировано дважды.
6. Убрать из актуального `GOJO_MANUAL` конфликтующие старые обещания: универсальный
   кастом-аватар/изменение тела, бесплатный встроенный browser TTS по умолчанию,
   усталость из нагрузки/отсутствия записей отдыха, «скучает» как основание давления.
   Сверить описание Browser Companion с принятыми Chrome+Brave и фактическим setup.

Промпт задаёт поведение модели, но не делает её выводы доказанными. Контроль полномочий,
сохранений и выбора предложения остаётся в существующих проверяемых модулях.
Реплика не валидирует факт сама; callers передают только актуальные данные своего аккаунта.

Дополнительные разрешённые правки `app.js`: тексты `restStateLine`, weekly context,
`runWeeklyReview`, chat-empty, `d_jarvis`, static rest nudge и late-evening observation
теперь различают записи и действительное состояние человека. Ключевые UI-строки
переведены на пять языков; расписание, выбор победителя и расчёт нагрузки не меняются.
Ответ nudge не сохраняется после смены аккаунта, write epoch или языка. Поздняя ошибка
прежнего аккаунта не ставит throttle новому. Legacy companion fallback тоже экранирует
обычный текст, чтобы отсутствие новой библиотеки не открывало HTML через имя питомца.
