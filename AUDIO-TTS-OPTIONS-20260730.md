# Satoru: варианты русского TTS для Тени

Дата проверки: 2026-07-30
Статус: исследование и рекомендация; код приложения не изменён.

> Цены, квоты и условия облачных сервисов меняются. Перед подключением биллинга их нужно повторно проверить по ссылкам ниже. Лицензионный раздел — инженерный аудит, а не юридическое заключение.

## Короткий вывод

Текущий системный `speechSynthesis` нельзя оставлять голосом Тени: качество и даже набор русских голосов зависят от ОС, браузера и установленных пользователем пакетов. Его стоит сохранить только как бесплатный аварийный fallback.

Для production-beta рациональный первый кандидат — **Google Cloud Chirp 3 HD, `ru-RU`**:

- на момент проверки есть 1 млн символов в месяц без оплаты за синтез, но биллинг всё равно требуется;
- после квоты — $30 за 1 млн символов;
- есть несколько мужских и женских русских голосов;
- квоты достаточно для реального закрытого теста, а не только для нескольких демо-фраз.

Перед окончательным выбором нужно провести слепой русский A/B-тест минимум между:

1. Google Chirp 3 HD: `Aoede`, `Kore`, `Leda`, `Zephyr`;
2. Azure MAI Voice 2: `ru-RU-Masha:MAI-Voice-2` и `ru-RU-Lev:MAI-Voice-2`;
3. ElevenLabs Multilingual v2 и Flash v2.5;
4. OpenAI `gpt-4o-mini-tts` как недорогим promptable benchmark;
5. Piper `ru_RU-denis-medium` как локальным fallback.

Если Azure `Masha` заметно лучше передаст образ спокойной, заботливой и иногда ироничной секретарши, production должен использовать **платный Azure tier**, а не F0. Если выиграет ElevenLabs, минимальный production-тариф — **Starter $6**, потому что Free не даёт коммерческой лицензии.

## Что требуется именно Тени

Критерии важнее красивой англоязычной демозаписи:

- естественный русский без «Google Translate»-интонации;
- правильные ударения, омографы, даты, числа, проценты, XP и имена;
- стабильная узнаваемая личность во всех репликах;
- спокойная «секретарша/Джарвис» в обычном режиме;
- отдельные оттенки: забота, серьёзность, ирония, тревога, радость, шёпот;
- быстрый старт короткой реплики;
- возможность остановить речь;
- кэширование повторяющихся утренних, вечерних, tutorial- и reward-реплик;
- безопасная серверная интеграция без API-ключа в браузере;
- аудиосигнал, от которого риг Тени сможет получать `speaking`, громкость и огибающую.

## Лицензионные ловушки

1. **«Есть бесплатная квота» не означает «можно использовать бесплатно в коммерческом приложении».**
2. ElevenLabs Free нельзя использовать для коммерческой Тени; аудио, созданное на Free, не становится коммерчески разрешённым после будущего апгрейда.
3. Azure F0 годится для теста, но не для commercial output prebuilt neural voices по текущим Product Terms. Production-реплики нужно генерировать уже на paid tier.
4. ElevenLabs Beta Services нельзя использовать в production даже на платном плане, пока действует Beta Services Addendum.
5. Silero CE и XTTS-v2 ограничены non-commercial использованием.
6. Piper требует отдельно проверить лицензию движка, конкретного voice model и исходного dataset. Нельзя считать все голоса одинаково разрешёнными.
7. Voice cloning допустим только с явным согласием владельца голоса и договором на нужные сценарии, срок и территории.
8. Для OpenAI нужно явно раскрыть пользователю, что он слышит AI-generated voice.
9. Перед релизом нужно сохранить PDF/снимок применимых тарифов и условий с датой, provider/model/voice ID и тарифом аккаунта.

## Рекомендуемый staged rollout

### Этап 0 — бесплатный baseline, 1 день

Не менять «личность» Тени вслепую. Сначала:

- привести Web Speech fallback в корректное состояние: дождаться `voiceschanged`, выбрать конкретный `ru-RU` voice, добавить `onerror`, cancel и настройку голоса;
- собрать один фиксированный русский test script;
- логировать provider/model/voice, длину текста, TTFB, полную latency, cancel/error;
- определить единую voice direction: «молодая взрослая секретарша; спокойная, тёплая, уверенная; без детскости, рекламы и радиоведущего».

### Этап 1 — слепой bake-off, 1–2 дня

Сгенерировать один и тот же набор реплик:

- Google Chirp 3 HD: `Aoede`, `Kore`, `Leda`, `Zephyr`;
- Azure: `Masha` и `Lev` в `friendly`, `caring`, `reflective`, `serious`;
- ElevenLabs Multilingual v2; отдельно Flash v2.5;
- OpenAI `gpt-4o-mini-tts`, голоса `marin` и `cedar`, с одинаковым русским voice prompt;
- Piper `denis-medium`.

Azure F0 и Eleven Free на этом этапе использовать только как evaluation. Не класть созданные ими файлы в production.

Минимум 5–10 русскоязычных слушателей оценивают без названий провайдеров:

- естественность;
- ударения и числа;
- соответствие личности Тени;
- отсутствие «робота/переводчика»;
- комфорт после десяти реплик подряд;
- latency короткой реплики;
- стабильность голоса между разными эмоциями.

Решение принимать по суммарной оценке, а не по одной эффектной фразе.

### Этап 2 — production-beta

Рекомендуемая стартовая схема:

1. **Primary:** победитель bake-off. По умолчанию начать с Google Chirp 3 HD, если он проходит порог качества.
2. **Challenger:** Azure `Masha` на paid tier, если её стили дают заметно лучшую личность.
3. **Fallback 1:** заранее сгенерированные локальные фразы для onboarding, утра, вечера, ошибок сети.
4. **Fallback 2:** Web Speech `ru-RU`, если нет сети/провайдер недоступен.

Не смешивать разные облачные голоса в одной пользовательской сессии: узнаваемость Тени важнее небольшой экономии.

Серверная архитектура:

- браузер вызывает только `/api/tts`;
- API key хранится только в server environment;
- сервер ограничивает размер текста, частоту запросов и месячный бюджет;
- cache key: `sha256(provider + model + voice + style + normalizedText + version)`;
- фиксированные onboarding/tutorial/morning/evening фразы предгенерируются;
- динамический текст синтезируется по требованию и кэшируется;
- ответ стримится в Opus/AAC/MP3; для минимальной latency можно использовать WAV/PCM только там, где оправдан трафик;
- запрос можно отменить через `AbortController`;
- если primary падает, приложение сначала ищет кэш/статическую реплику, потом использует Web Speech;
- суммы, даты, XP и сокращения преобразуются в произносимый русский до TTS.

Контроль расходов:

- hard cap на символы одной реплики;
- per-user rate limit;
- daily/monthly provider budget;
- billing alerts до 50/80/100% квоты;
- повторные реплики всегда из кэша;
- длинный текст Тень резюмирует и произносит короткую версию.

### Этап 3 — связь голоса с ригом Тени

Не ждать полноценного lip-sync API:

- `speaking=true` включает talking-loop;
- `AnalyserNode` даёт RMS/огибающую для пульса ядра, свечения, формы рта и дымки;
- `onended` возвращает idle;
- sentence boundaries переключают жесты;
- preset эмоции (`friendly`, `serious`, `warning`, `celebrate`) выбирают и стиль TTS, и animation state;
- при отсутствии доступного raw audio у Web Speech использовать синхронный упрощённый talking-loop по событиям `start/end/boundary`.

Так движение останется синхронным при любом провайдере, а более точные viseme/word timings можно добавить позже.

### Этап 4 — приватный offline-mode

После product validation:

- поднять Piper как отдельный локальный/sidecar сервис;
- сначала проверить `denis-medium`, затем остальные русские голоса;
- провести legal review GPL-3.0 и конкретной voice model;
- не заставлять мобильную PWA скачивать модель порядка десятков мегабайт по умолчанию;
- позиционировать local TTS как privacy/offline fallback, а не как основной голос, пока он не выигрывает слепой тест.

### Этап 5 — собственный голос Тени

Если персонаж действительно становится ядром Satoru:

- нанять актрису/актёра;
- получить явное согласие на synthetic voice и прописать продукт, территории, срок, retraining и отзыв согласия;
- создать лицензированный custom voice у выбранного провайдера либо обучить свою модель на разрешённом датасете;
- заморозить voice identity и версионировать изменения.

Это единственный устойчивый способ не зависеть от исчезновения или изменения preset-голоса провайдера.

## Русский test script для bake-off

Все сервисы получают одинаковый текст и одинаковое назначение эмоции.

### Нейтральный помощник

1. «Доброе утро. Сегодня у тебя три важных дела и одна привычка, которую легко закрыть за пять минут».
2. «Сначала разберём план, потом выберем награду. Я рядом, но решение остаётся за тобой».
3. «До следующего уровня осталось тысяча двести сорок семь очков опыта».

### Числа, даты и сокращения

4. «Во вторник, двадцать восьмого июля, фокус длился сорок семь минут».
5. «Ты выполнил восемьдесят три процента плана и получил двести пятьдесят XP».
6. «Награда стоит две тысячи восемьсот двадцать четыре монеты».

### Ударения и омографы

7. «Старинный замок закрыт, а дверной замок всё ещё открыт».
8. «На столе лежит атлас, а Атлас держит небесный свод».
9. «Это стоит проверить: герой стоит у ворот и ждёт сигнала».
10. «Тень узнала всё вовремя, хотя раньше не знала ответа».

### Эмоции

11. Забота: «Ты устал. Давай уменьшим план, а не будем делать вид, что ресурса ещё много».
12. Серьёзность: «Серия под угрозой. Осталась одна короткая задача».
13. Радость: «Есть! Сложный квест закрыт, и сундук уже ждёт тебя».
14. Рефлексия: «Сегодня получилось не всё, но направление ты сохранил».
15. Тихая ирония: «Пять новых целей за минуту. Смело. Теперь выберем одну настоящую».
16. Шёпот: «Не буди питомцев. Я просто напомню про вечерний итог».

### Имена и продуктовые слова

17. «Сатору подготовил план, а Клинг поможет оживить следующую форму Тени».
18. «Traveller сменил плащ, амулет и цвет волос».
19. «Режим белого шума включён. Наушники уже на Тени».
20. «Если голос недоступен, текст останется на экране».

## Acceptance gate

Провайдер допускается в production только если:

- медианная оценка естественности и соответствия персонажу не ниже 4 из 5;
- ни одна критическая продуктовая фраза не получает неверное ударение;
- 95-й перцентиль старта короткой реплики приемлем на мобильной сети;
- cancel работает сразу;
- есть подтверждённые коммерческие права именно для выбранного тарифа/model/voice;
- месячный worst-case budget ограничен технически;
- при отказе API Тень не молчит и не ломает интерфейс.

## Финальная рекомендация

1. Провести бесплатный/минимально платный слепой bake-off.
2. Если Google Chirp 3 HD проходит качество — запустить его в закрытой beta с лимитом и кэшем.
3. Если Azure `Masha` выигрывает заметно — подключить paid Azure и сделать её единым голосом Тени.
4. ElevenLabs использовать только на paid plan и только если его выигрыш в характере оправдывает меньшую квоту.
5. `gpt-4o-mini-tts` держать как promptable benchmark/вариант быстрой серверной интеграции.
6. Web Speech оставить аварийным fallback.
7. Piper исследовать как отдельный privacy/offline режим, не как обязательный вес мобильного клиента.
