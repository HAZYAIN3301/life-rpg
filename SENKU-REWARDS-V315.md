## Что построено

**Каждая законченная сессия после подключения → выполненный квест** с обычной наградой:
XP и золото считает та же `itemXp`/`itemGold`, что и для любого квеста (минуты × сложность
«обычная» + бонус выполнения, бонусы снаряжения и перков как обычно). Запись — обычная
`Store.updateNow('tasks')` с подтверждением сервера, тот же путь, что у выполнения квеста.
Квест лежит в своём дне, в сфере колоды, с названием «Senku: Descubrimiento — 22 карточки».

- **Смешанная сессия** (поездка по папке, учёба по нескольким колодам) делится по сферам:
  минуты — по доле карточек, не меньше минуты. Испанский 12 карточек и биология 9 из одной
  поездки — два квеста в двух сферах.
- **Сфера колоды:** запомненный выбор → ИИ (только если человек разрешил) → совпадение
  названия колоды/папки с названием сферы → история квестов → «сфера по умолчанию».
  Найденное запоминается для следующих сессий; «по умолчанию» — нет, чтобы ИИ или ручной
  выбор позже могли его заменить.
- **Разовый выбор перед первым начислением:** на «Сегодня» карточка «Senku теперь даёт
  награды» — «С помощью ИИ» / «Только по названиям» и сфера по умолчанию. До выбора ничего
  не начисляется: иначе накопленные с подключения сессии ушли бы в сферу по умолчанию раньше,
  чем человек решил. Выбор «С помощью ИИ» — это и есть согласие показывать ИИ названия колод.
- **Настройки → Senku:** с какой даты идут награды, переключатель ИИ, сфера по умолчанию,
  список колод со сферой и пометкой, кто её выбрал (ИИ / по названию / по истории / вручную /
  по умолчанию). Новый выбор действует для следующих сессий.
- **«Сегодня»:** квесты Senku видны в общем списке дня как выполненные; в строке Senku у
  каждой сессии — «квест засчитан», «награда в пути» или «до подключения — без награды».

## Одна награда на сессию

- Сессия = вид + начало (`voice|2026-10-01T06:52:00.000Z`); каждый квест из неё хранит этот
  ключ (`senkuKey`).
- Сервер отдаёт `GET /api/bridge/senku/pending` — законченные сессии с доверенной
  длительностью (≤ 6 ч), начатые не раньше подключения, ещё без отметки. Клиент создаёт
  квесты и **только после записи** отмечает их `POST /api/bridge/senku/claim`.
- Если отметка не дошла — следующий заход найдёт квест по ключу и отметит без второй награды.
  Если человек удалил квест — отмеченная сессия повторно не начисляется. Два устройства
  одновременно — один набор квестов (ключ одинаковый).
- Отметки хранятся в том же серверном файле `senku-bridge.json` и записываются атомарно.
  «Отключить» удаляет их вместе с ключом; уже созданные квесты остаются.
- Незакрытые сессии (`endedAt: null`) ждут закрытия; дольше 6 часов — без награды
  (длительности нет доверия, как и в фазе 1).

## ИИ и приватность

- Названия колод и папок уходят ИИ только при включённом согласии; вызов — через общий
  механизм приложения (`aiSurfaceRun('senku')`: отмена, таймаут 30 с, смена аккаунта).
  Сбой ИИ не мешает награде — колода идёт по названию или в сферу по умолчанию.
- ИИ видит только id и названия колод и путь сфер; ответ принимается только с известными id.
- Ключ Senku по-прежнему только на сервере; ни ключ, ни названия колод не пишутся в журнал.

## v316 — дополнения контракта Senku (01.10)

Агент Senku выполнил просьбы Satoru, `version` остался 1: `rideId`, `deckMs` (сумма по прогону =
`durationMs`), `state` (`open`/`stopped`/`finished`), `endedBy` (`device`/`timeout`; сервер Senku
закрывает сессию после 30 минут без карточек, `endedAt` = последняя карточка), страницы
`limit`/`more`. Satoru (v316):

- **Читает новые поля как необязательные:** записи, сохранённые до 01.10, Senku заново не
  пересылает — оба вида годны (тесты на старом и новом образце; старый лежит как
  `scripts/fixtures/senku-facts-v1-20260928.example.json`). Новые поля проверяются строго:
  неизвестное состояние или расхождение `state` с `endedAt` — запись пропускается.
- **Страницы:** запрос с `limit=1000`; при `more: true` следующая страница сразу с
  `since = nextSince`, каждая страница записывается вместе с курсором; до 10 страниц за раз,
  остаток — при следующем обращении без ожидания.
- **Время колоды:** минуты квестов смешанной сессии берутся из `deckMs`, если оно есть у всех
  колод сессии; иначе — по доле карточек, как раньше.
- **Закрытие по таймауту и продолжение:** закрытая сессия награждается сразу. Если Senku потом
  откроет её снова и она вырастет, сервер Satoru предлагает **только разницу** (карточки и
  время сверх уже награждённого) — отдельный квест с ключом `…#1`, `…#2`. Отметка хранит, что
  было награждено (`seq`, карточки и время по каждой записи); устаревший номер не засчитывается,
  поэтому два устройства не наградят разницу дважды. Отметки v315 (просто время) окончательны.
- Проверено: 19 тестов моста + 6 модуля наград, полный набор **3257/3257**; браузер Chromium и
  WebKit на синтетике — поездка по трём колодам с `deckMs` (12/9/4 мин), сессия глазами закрыта
