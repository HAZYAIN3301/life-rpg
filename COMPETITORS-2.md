# Satoru — глубокий разбор «комнатных»/аватарных конкурентов (2026-06-20)

Альберт скинул 4 сильных приложения и просил разобрать **всё приложение целиком**, не только косметику. Цель — перенять лучшее + спроектировать «комнату персонажа» и полный рескин «Системы».

---

## 1. Spirit City: Lofi Sessions ⭐ (эталон по Альберту — «шикарная реализация»)
**Что это:** уютный «фокус-санктуарий». Твой кастомный аватар сидит в **кастомной комнате**; лофи-саундтрек + динамические эмбиент-звуки (дождь, костёр); внутри комнаты — to-do, сессионный таймер (помодоро), трекер привычек, дневник.
**Петля:** XP за хорошие привычки → анлок косметики (аватар: причёски/одежда/цвета + **декор комнаты: обои, пол, мебель, настенный декор**).
**Фишка «Spirits»:** духи появляются, когда ты фокусируешься / экспериментируешь с активностями/звуками/декором; каждый становится **компаньоном рядом, которого можно погладить**.
**Почему работает:** продуктивность ощущается как «обживание личного убежища», а не список дел. Присутствие + атмосфера + владение пространством.
**Стащить:** 🏠 **КОМНАТА как домашний экран** (персонаж + питомцы живут в кастомном уютном пространстве); эмбиент-аудио; косметика украшает И аватар, И комнату; таймер фокуса встроен прямо в сцену; «духи» = наши компаньон+питомцы, ambient-присутствующие.

## 2. SelfQuest ⭐ (эталон по АВАТАРУ + ГИРУ)
**Что это:** пиксельная RPG. Строишь героя, вступаешь в гильдию, бьёшься с друзьями, квесты мапятся на реальный фитнес/привычки; каждая тренировка/дело → XP, золото И **гир, который ВИДИМО надевается на пиксель-персонажа** (шлем, броня, перчатки, ботинки, кольца, оружие — рарности E/N, +уровни). Вкладки Character / Job / Details. Данжи, PvP, карта-замок. Сильное Discord-комьюнити.
**Почему работает:** ты ВИДИШЬ, как персонаж крепнет и одевается — гир носится на теле, прогресс зримый. «Прокачайся как аниме-персонаж».
**Стащить:** 🛡 **гир видимо надет на аватаре** (у нас гир — абстрактные %-бонусы; показать на теле), система «Работа/класс», данжи (у нас есть программы-данжи), сильные соц-хуки (Discord).
**Избегать:** PvP-битвы (соревнование с наказанием — против нашей философии; держим кооп).

## 3. Skillion (полированный RPG-скилл-фрейминг + аватар)
**Что это:** кастомные навыки как левелуемые RPG-скиллы (= наши сферы), дела→эпик-квесты→XP, анлок ачивок, **полированный аватар-креатор** (живописный, не пиксель — волосы/глаза/нос/рот, рандом-кубик), еженедельный **«Spotify Wrapped»**, эпичные левелап-анимации, RPG-инвентарь-эстетика (иконки предметов в фоне). Монетизация: **премиум за шеринг в соцсетях** (до года бесплатно).
**Почему работает:** фэнтези-эстетика + кастомные навыки + эпичные моменты-празднования. Share-to-unlock-premium = виральный рост.
**Стащить:** 📊 **еженедельный Wrapped** (у нас в бэклоге), эпичная **левелап-анимация-момент**, **share-to-unlock-premium** (рост), полированный аватар.

## 4. Gizmo (наука + соц-обучение)
**Что это:** ИИ-флешкарты из любого контента (PDF/YouTube/заметки), **интервальное повторение** (научно-обоснованное расписание), геймифицированные квизы, XP, **лидерборды + «академии»** (учебные группы).
**Почему работает:** делает скучное (зубрёжку) аддиктивным через науку + соревнование. ИИ берёт тяжёлую работу (контент→учебный материал).
**Стащить:** 🧠 **интервальное повторение для ресёрфейса** (всплывать цели/рефлексии/записи дневника в оптимальные интервалы — сшить с чек-инами компаньона), «академии» (= наши пати, но тематические), ИИ контент→структура (у нас есть ИИ-импорт).
*(Примечание: чистый «питомец-кормёжка-учёбой» — это родственный StudyPet, не Gizmo; у Gizmo ядро = ИИ + интервалы + соц-академии.)*

## Сквозные паттерны лучших (что общего)
1. **«Дом», который обживаешь** (комната Spirit City) — не список задач, а место. Присутствие.
2. **Зримое воплощение** — прогресс = персонаж, которого ВИДИШЬ меняющимся (гир SelfQuest, аватар Skillion, комната Spirit City).
3. **Ambient-компаньоны** — питомцы/духи рядом, гладятся (Spirit City, StudyPet).
4. **Атмосфера/аудио** — лофи + саундскейпы делают фокус приятным (Spirit City).
5. **Моменты-празднования** — эпичные левелап-анимации (Skillion, SelfQuest).
6. **Косметика-драйвер удержания** — XP → анлок аватара + декора комнаты (все).
7. **Сообщество** — гильдии, академии, лидерборды, Discord (SelfQuest, Gizmo, Skillion).
8. **Виральная петля** — share-to-unlock-premium (Skillion).

## Где Satoru уже сильнее / уникален
ИИ-слой (почти ни у кого) · честная калибровка существующего уровня · кастомные сферы N-уровней · мультиплеер **без вины** · метод «Атомные привычки» · zero-dep self-host + BYOK · кросс-платформа PWA+APK · **тёплый компаньон + питомцы-десятиборье** (уже есть!). Spirit City уютный, но мелкий по RPG/ИИ; SelfQuest глубокий, но гриндовый/наказывающий. **Наша незанятая зона: уютная-комната + глубокая RPG + тепло + ИИ.**

## Карта на запросы Альберта

### A. 🏠 Логово (Комната персонажа) — ФЛАГМАН
Фьюжн Spirit City + SelfQuest: вью «Логово» = твой аватар в кастомной комнате, рядом компаньон «Тень» + питомцы из зверинца, встроенный таймер фокуса, тумблер эмбиент-звука, косметика украшает аватар И комнату. Аватар **отражает состояние**:
- **КБЖУ/действия** → телосложение/поза (у нас есть `figureSVG` по полу/весу/силе; расширить: поза/аура по энергии и форме — устал при низкой энергии, бодр при активности).
- **носит купленные предметы** (гир/косметика на теле — модель SelfQuest).
- питомцы present в комнате.
Это объединяет аватар + питомцев + компаньона + гир + косметику + фокус в ОДНО обживаемое пространство. Сильнейший ход удержания по разбору.

### B. ⚡ Полный рескин «Системы» v2
За пределы нарратора: при включённом режиме **весь UI преображается** (Solo-Leveling «синее окно Системы»): циан/тёмные панели, моно-заголовки, «STATUS WINDOW» для экрана персонажа, квесты как «QUESTS [DAILY]», скан-линии, рамки-уголки. Цельный скин, не только всплывашки.

### C. 🍱 Аватар отражает КБЖУ/питание
Нужен опциональный ввод КБЖУ/калорий → влияет на аватар (+, возможно, на энергию). Новое измерение трекинга (у нас есть вес/рост/%жира — добавить дневной лог).

## Рекомендации (приоритет)
**🟢 Делать:**
1. **Логово (Комната)** — флагман. Аватар + питомцы + надетый гир + уютная сцена + встроенный таймер + эмбиент-тумблер. Фьюжн Spirit City + SelfQuest. Дом, который делает Satoru *местом*.
2. **Гир видимо на аватаре** (SelfQuest) — наш абстрактный гир показать на теле.
3. **Рескин «Системы» v2** (Solo Leveling) — цельный скин.
**🟡 Обдумать:**
- Эмбиент-саундскейпы (дождь/огонь/лофи) — киллер-фича Spirit City, но тяжело по аудио-ассетам (royalty-free паки ок).
- Еженедельный Wrapped + эпик-левелап-анимация (Skillion).
- Интервальное всплывание рефлексий/целей (Gizmo).
- Share-to-unlock-premium — виральный рост (Skillion).
- КБЖУ-лог → аватар + энергия (идея Альберта).
**🔴 Осторожно:** PvP-битвы (SelfQuest) — соревнование без вины = наша линия, держим кооп.
**⭐ Удваивать:** тепло + присутствие-комната + ИИ + свои сферы + без-вины — незанятая комбинация Satoru.
