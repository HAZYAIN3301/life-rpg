# Avatar 3D pilot — проверка 2026-09-07

**Исторический Engineering PASS; пользовательская визуальная приёмка — FAIL (07.09).**
Руки/шея, хват меча через запястье, ходьба спиной, выворот руки при поглаживании,
«кирпичные» элементы и волосы отвергнуты пользователем. Технические проверки ниже
не измеряли эти дефекты и не дают права внедрять модель. Production остаётся прежним.
База репозитория: `c22acbd341e0c0accfe30a01c142bbed40035640`.
Это отдельный factory-инструмент. Ни новая внешность, ни магазин не выпущены в Satoru.

## Подтверждено

- `npm test`: **6/6 PASS**; внутри проверки общего скелета — **1536** сочетаний
  одежды/поз/моментов. Кости и геометрия не пересоздаются при переодевании.
- Имена контрактных костей, слотов и точек контакта уникальны. Это предотвращает
  переименование socket экспортёром и ошибку ладони после обратного импорта.
- `npm run qa:browser`: **PASS**, отдельный Chrome/Playwright context, localhost.
  Полный [отчёт](./outputs/browser-report.json).
- **256** браузерных geometry samples без ошибок; экспорт/импорт четырёх настоящих
  GLB-клипов и **16** контрольных моментов импортированной анимации.
- GLB: **898536 bytes**. При проверенных моментах максимальная ошибка palm-contact
  ~0.0000073 m, минимальная высота подошвы ~−0.000065 m (интерполяция baked keys).
  Это проверка заданного socket, не всей поверхности руки/шерсти.
- Через реальные UI-controls: скачать GLB → открыть его → тот же выбранный look.
  Невалидный файл отвергнут, прежняя модель остаётся на месте.
- Look восстанавливается после reload из отдельного localStorage ключа.
  Загруженный пользователем GLB сам по себе в localStorage не сохраняется.
- Воспроизведение действительно меняет время; pause его останавливает.
  Reduced motion проверен во время воспроизведения, затем проверено возобновление
  после смены preference. Hidden/offscreen дополнительно проверены чистым motion gate;
  реальный уход в фон физического мобильного устройства здесь не проверялся.
- Desktop 1280×900; mobile 375×812 и 360×812 — нет горизонтального overflow,
  видимые проверяемые controls >=42 px. Скриншоты просмотрены, не только DOM-asserts.
- Нет page errors и внешних сетевых запросов. Preview server не отдаёт data/, .git,
  package.json или выход за разрешённый каталог через traversal.
- Связанные корневые documentation/UI gates: **15/15 PASS**.
  Полный runtime suite не запускался: public/server/main dependencies не менялись.

## Что PASS не означает

- Манекен намеренно простой: грубые плечи/шея, примитивные волосы и материалы.
  **Не утверждён как Traveller.** Кодогенерация геометрии не решила художественный этап.
- Метрики проверяют конечность vertex positions, веса, bones, grip и заданный pet target.
  Они **не доказывают** отсутствие всех самопересечений/схлопывания ткани и скольжения стопы.
- Sit/pet — статусы с микродвижением. Красивые переходы между ними не сделаны.
- Растровый питомец работает как временный 2D-слой; боковой ракурс не превращает его в 3D.
- Chrome использовал software WebGL (SwiftShader) для воспроизводимого QA.
  **FPS/батарея на физическом телефоне не измерены.** 57 draw calls / 12546 rendered
  triangles в одном проверенном кадре — диагностические числа, не performance approval.
- Нужны художественный style/rig test, полная garment/contact QA и замеры устройства.
  Далее — отдельная интеграция в Character/Den/portrait и server-owned inventory.

## Исправления, найденные проверками

1. Обратный порядок колец ноги/руки выворачивал видимую сторону mesh → нормализован winding.
2. В ходьбе нога не доставала до пола в части цикла → исправлена высота таза.
3. Mesh ладони назывался как PalmL socket → после GLB export/import выбирался другой узел,
   ошибка контакта составляла 0.026 m. Имена разделены; regression проверяет уникальность.
4. В browser QA ожидание media-change теперь событийное, не предположение, что preference
   и слушатель применяются в одном синхронном шаге.
