# Гайд «Тень ведёт тебя» — план (spec для ultracode)

> Игровой пошаговый онбординг: маскот Тень учит ДЕЛАЯ, по одному шагу, без перегруза, с текстом+звуком, на реальном приложении. Self-contained, по фазам, DEVLOG на каждую. Принцип Альберта: «сделать сложное простым в использовании — ручеёк».

## Зачем (проблема)

- Сейчас онбординг = разовый выбор сфер (`renderOnboardingScreen`, app.js) + **стена текста** «📖 Как играть» (модалка, ~app.js:5469) = перегруз.
- ИИ-чат-гид (FAB, `GOJO_MANUAL`) — реактивный, нужен ИИ-ключ.
- **Дискаверабилити — дыра:** фичи спрятаны (гейт ур.3, режим «Система», питомцы, дерево), Альберт сам не нашёл «Систему»; жалобы «непонятно как трекать выполнено» (fb_mql0zrqi43ws). Пульс-точки (`settings.discovered`) — полумера.
- Маскот «Тень» уже есть (компаньон, чек-ины, связь) — идеальный ведущий.

## Принципы

1. **Учёба через действие, не чтение.** Шаг = одна мысль + одно реальное действие + мгновенная видимая награда (XP-анимация + SFX уже есть).
2. **Один шаг за раз, спотлайт.** Затемнение + вырез-подсветка нужного элемента + пузырь Тени со стрелкой. Нельзя потеряться.
3. **Анти-перегруз = капельница.** День 1 — только core loop. Привычки/Дерево/Логово/питомцы Тень открывает в следующие заходы, в нужный момент (чинит «фичи спрятаны»). Сшить с `settings.discovered`.
4. **Реальное приложение, не песочница.** Первый квест настоящий, награда настоящая.
5. **Skippable / resumable / replay.** Из «?». Прогресс в `settings.tutorial`.
6. **Текст + звук сразу; голос (TTS) — позже** (аудио-ассеты/ключ, как музыка #23b).

## Фаза 1 — Движок туториала + спотлайт-оверлей

- **Данные шага** `TUTORIAL_STEPS = [{ id, say (реплика Тени), target (CSS-селектор для подсветки, опц.), advanceOn (что завершает: action-имя / событие / 'next'-кнопка), reward (опц.), once }]`.
- **Состояние** `settings.tutorial = { step: <id|null>, done: [ids], skipped: bool, seenDrips: [] }`. Персист (Store.save settings).
- **Драйвер** `tutorialStart()/tutorialNext()/tutorialAdvance(action)/tutorialSkip()`:
  - рисует **оверлей**: полупрозрачный фон, вырез по `getBoundingClientRect()` таргета (mask/clip или 4 затемняющих дива), пузырь Тени рядом с таргетом (мини-портрет Тени из `shadowVideo`/постер + текст), кнопки «Дальше»/«Пропустить».
  - **продвижение по действию:** хук в существующий делегированный обработчик кликов (`data-action`) — после выполнения нужного действия (напр. `complete-quest`) вызвать `tutorialAdvance('complete-quest')`. Минимально-инвазивно: одна строка в конце `render()` или в обработчике.
  - SFX на каждый шаг (есть `sfx()`), завершение шага — радостный звук + реплика Тени.
- **Доступность:** `prefers-reduced-motion`, фокус-трап в пузыре, кнопка закрыть, не блокировать критичное.

Acceptance: оверлей подсвечивает любой элемент по селектору; пузырь Тени читается; шаг продвигается по действию И по кнопке; состояние персистится; skip/replay работают.

## Фаза 2 — Шаги Дня 1 (core loop через действие)

Последовательность (черновик, докрутить тексты под голос Тени):
1. Тень здоровается: «Я — Тень, твой спутник. Покажу, как это работает — за минуту, на деле.»
2. **Создай первое дело** → спотлайт на поле быстрого ввода/кнопку «+ Квест» → юзер вводит → advance.
3. **Заверши его** → спотлайт на ✓ → `complete-quest` → **XP-анимация + золото + звук**, Тень: «Видишь? Дело превратилось в рост.»
4. **Посмотри прогресс** → спотлайт на полосу уровня/карточку День → Тень объясняет уровень = доказанное мастерство (не сгорает).
5. **Фокус (опц.)** → показать ▶ таймер одним предложением.
6. **Связь со мной** → спотлайт на чек-ин Тени → Тень: «Заглядывай ко мне утром/вечером.» → завершение Дня 1 + **награда** (звание «Посвящённый» / косметика / +связь).

Каждый шаг: одно действие, мгновенная отдача, ≤2 предложения текста.

Acceptance: новый юзер проходит День 1, делая реальные действия; на выходе у него есть выполненный квест, виден уровень, понятен чек-ин; награда выдана; «непонятно как трекать выполнено» закрыто.

## Фаза 3 — Капельница (drip) остальных разделов

Не сразу — по триггерам в следующие заходы (анти-перегруз):
- После N выполненных дел / 2-го дня → Тень: «Готов к привычкам?» → мини-тур вкладки Привычки.
- При ур.3 (раздел Герой/Племя открывается) → Тень показывает Логово, питомцев, дерево навыков — по одному, не всё разом.
- Режим «Система», награды, цели-горизонты — точечные подсказки Тени в момент релевантности.
- Заменяет/усиливает пульс-точки `discovered`: вместо немой точки — Тень словами ведёт.
- Каждый дрип once, отмечается в `tutorial.seenDrips`, не навязчив (≤1 за заход), всегда skip.

Acceptance: разделы открываются «по руке Тени» постепенно; ничего не вываливается разом; всё пропускаемо; не повторяется.

## Риски / решения

- **Спотлайт-позиционирование** (особенно mobile, элементы у краёв, скролл) — пузырь авто-флипает сторону; при отсутствии таргета — центр-модалка.
- **Реальные действия в туториале меняют данные** — это ОК (учимся на настоящем), но первый квест/награду не считать читом (обычный путь).
- **Не бесить** — всё skip/resume; дрип ≤1 за заход; «больше не показывать».
- **Голос/TTS** — вне scope v1 (текст+SFX). Озвучка = отдельная задача (ассеты), как музыка #23b.

## TL;DR

Маскот Тень ведёт нового игрока по одному действию за раз (спотлайт+пузырь+звук), на реальном приложении: создал дело → выполнил → увидел рост → познакомился со мной. Остальное Тень открывает капельно в следующие заходы. Чинит главную дыру — дискаверабилити — в стиле «ручеёк».
