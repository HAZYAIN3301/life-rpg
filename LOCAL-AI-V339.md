# Локальная модель для всех — v339

> 05.10.2026, Claude. Запрос владельца: ИИ от локальной модели на своём компьютере (Ollama), «от
> частного к общему» — удобная настройка для любого пользователя. У владельца: Edith (MacBook Pro M5
> Pro, 24 ГБ, `qwen3.5:9b-mlx`) и Jarvis (MacBook Air, 8 ГБ, всегда включён, `qwen3.5:2b`).
> До сих пор (v268) Ollama работала, только если сам сервер Satoru стоит на том же Mac; продакшен до
> неё не дотягивался. Это пункт 2 «Next increments» из `SECRETARY-OLLAMA-V268.md`.

## Как устроено

- **Компьютер сам приходит за заданием.** Коннектор (`local-ai/connector.sh`, только `sh` и `curl`)
  держит исходящее соединение с Satoru (долгий опрос 25 с), получает готовое тело запроса
  `/api/chat`, отдаёт его Ollama на `127.0.0.1:11434` и возвращает ответ. Наружу ничего не открывается,
  Ollama не публикуется, облака в цепочке нет. Других адресов Ollama коннектор не трогает
  (только `/api/tags` и `/api/chat`).
- **Привязка по одноразовому коду (10 минут).** Настройки → Тень и подключения → «Локальная модель»
  → «Подключить компьютер» → одна команда в Терминал:
  `curl -fsSL https://satoruapp.com/local-ai/install.sh -o satoru-local-ai.sh && sh satoru-local-ai.sh <код>`.
  Скрипт сначала сохраняется и только потом запускается (его можно прочитать). Установщик проверяет
  Ollama, получает ключ компьютера (хранится в `~/.satoru-local-ai`, права 600; на сервере — только
  хэш), ставит автозапуск: macOS — LaunchAgent, Linux — `systemd --user`, иначе — запуск вручную.
  Windows — позже.
- **Несколько компьютеров по порядку** (до пяти): отвечает первый в сети. «Сначала этот» меняет
  порядок. Для владельца: Edith отвечает, пока открыта; уснула — Jarvis.
- **Уснувший компьютер не держит запрос.** Коннектор подтверждает получение задания; нет
  подтверждения 5 с (соединение осталось от закрытого ноутбука) или задание не забрали 10 с —
  задание уходит следующему компьютеру, иначе сразу «компьютер не в сети». Позднее подтверждение
  отвергается, коннектор задание пропускает.
- **Модель.** Список приходит с компьютера; облачные псевдонимы Ollama (`remote_*`, «cloud»),
  модели только для эмбеддингов и без `completion` отбрасываются. Первой выбирается самая крупная
  установленная. Модель с `vision` читает и фото расписания — фото тогда не уходит в облако.
- **Без отката в облако.** Выбрал локальную модель — ответ локальный или понятная причина: не в сети,
  занята, не ответила за 3 минуты, модель не выбрана, запрос слишком длинный, компьютер не подключён.
  В чате причина пишется в разговоре, вопрос остаётся в поле.
- **Отключение** в Настройках отзывает ключ; коннектор на следующем запросе удаляет себя (файлы и
  автозапуск). Вручную: `sh ~/.satoru-local-ai/connector.sh --uninstall`.
- Если других ИИ нет, первый подключённый компьютер сразу становится ИИ по умолчанию; иначе — кнопка
  «Использовать по умолчанию». «Проверить» — короткий ответ модели и время.
- Режим v268 (Ollama рядом с сервером, переменные `SATORU_OLLAMA_*`) остаётся для своей установки.

## Файлы

`server-local-ai-v1.js` (посредник: привязка, ключи, очередь, подтверждение, выбор компьютера),
`local-ai/install.sh`, `local-ai/connector.sh` (отдаются сервером с адресом сервера внутри; адрес
фильтруется, заголовки запроса не попадают в shell), маршруты `/api/local-ai/*` в `server.js`,
блок «Локальная модель» в `public/app.js`. Данные — `data/users/<id>/local-ai.json`, серверные
(недоступны через `/api/data`, не входят в экспорт).

## Проверено

- Тесты: посредник (11), сквозной — настоящий сервер + настоящие install.sh и connector.sh во
  временном HOME + поддельная Ollama (установка, ответ в чате, проверка, отзыв, самоудаление, только
  `/api/tags` и `/api/chat`); обновлён v267 (без компьютера — понятная причина, модель не вызывается).
- Браузер WebKit iPhone и Chromium 1280, поддельная Ollama: подключение по команде, выбор модели,
  «Проверить» (0,4 с), ответ Тени, «уснувший» компьютер (процесс заморожен) — «не в сети» через 5 с,
  вопрос в поле; проснулся — снова в сети; отключение — коннектор вышел, файлы удалены.
- **Разово на настоящей Ollama этого Mac** (0.35.1, `qwen3.5:9b-mlx`, синтетические вопросы,
  временная папка, без автозапуска): «Проверить» 4,6 с с загрузкой модели; чат «2+2» → «4» за 0,6 с;
  разбор «дзюдо по вт и пт 18:00–19:30, бег по субботам минут 40» верный за 5 с; фото синтетической
  таблицы — 16 строк по сферам за 22 с, но с ошибкой столбцов (часть уроков сдвинута на соседний
  день): у 9B-модели чтение фото слабее облачной, строки надо проверять перед сохранением.
- **Не проверено:** Linux и `systemd --user` вживую (синтаксис проверен в `dash`), LaunchAgent вживую
  (проверка — без автозапуска, на машине владельца ничего не ставилось), Windows (нет).
