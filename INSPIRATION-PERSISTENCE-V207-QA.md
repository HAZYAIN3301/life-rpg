# Inspiration Persistence v207 — сохранение ответов настройки

Дата: 2026-08-30
Статус: release candidate; production-проверка фиксируется после публикации.

## Ошибка

Редактор «Вдохновения» восстанавливал только уже подтверждённый профиль. Ответы текущего
редактирования жили только в DOM до нажатия нижней кнопки, поэтому закрытие окна, reload или
сбой записи уничтожали заполненную форму. Дополнительно собственная формулировка интересов
терялась даже после сохранения: runtime при повторном открытии явно подставлял пустую строку.

## Новый контракт

- Любое изменение ответов сохраняет отдельный `settings.inspirationDraft` после короткого debounce.
- Закрытие редактора сначала принудительно записывает последний черновик и только затем закрывает
  окно; при ошибке окно остаётся открытым с честным сообщением.
- Повторное открытие сначала восстанавливает черновик, затем подтверждённый профиль.
- Перед выгрузкой страницы выполняется bounded keepalive-запись последнего состояния формы.
- Финальная кнопка сохраняет нормализованный `settings.inspiration` и удаляет черновик одной
  записью настроек. До успешного ответа интерфейс не сообщает об успехе.
- Собственный текст интересов теперь является частью нормализованного профиля, ограничен 300
  символами и снова появляется при редактировании.
- Подпись кнопки различает первый запуск и редактирование: «Показать мою подборку» / «Сохранить
  интересы». Рядом явно указано, что черновик сохраняется автоматически.

## Совместимость и приватность

- Черновик хранится в уже существующем account-owned `settings`, не в новом стороннем хранилище.
- В каталог и подборку попадает только финально подтверждённый профиль; незавершённый черновик не
  меняет рекомендации.
- Очистка аккаунта отменяет pending Store write, медиазахват и таймер черновика до обнуления State.
- Offline shell и изменённые runtime-файлы синхронно подняты до `satoru-v207`; неизменённые модули
  не перепинованы без причины.

## Production gate

После push должны быть проверены с cache-buster:

1. `index.html` закрепляет `inspiration-profile-v1.js`, `return-shelf-ui-v1.js`, `styles.css` и
   `app.js` на v207.
2. `sw.js` и `app.js` сообщают `satoru-v207`.
3. production `inspiration-profile-v1.js` содержит профиль v1.2.0 и `customInterests`.
4. В реальном аккаунте: заполнить часть формы → закрыть → открыть → ответы на месте; затем сохранить
   финально → открыть ещё раз → подтверждённые ответы на месте, черновик очищен.
